# Problem Title: Merge Sorted Array (LeetCode 88)

## Problem Statement
You are given two integer arrays `nums1` and `nums2`, sorted in **non-decreasing order**, and two integers `m` and `n`, representing the number of elements in `nums1` and `nums2` respectively.

Merge `nums2` into `nums1` as **one sorted array**.

> [!IMPORTANT]  
> The final sorted array should not be returned by the function, but instead be stored inside the array `nums1`. To accommodate this, `nums1` has a total length of $m + n$, where the first $m$ elements denote the elements that should be merged, and the last $n$ elements are set to `0` as placeholders and should be overwritten.

---

## Sample Examples

### Example 1
- **Input:** 
  - `nums1 = [1, 2, 3, 0, 0, 0]`, `m = 3`
  - `nums2 = [2, 5, 6]`, `n = 3`
- **Output:** `nums1 = [1, 2, 2, 3, 5, 6]`
- **Explanation:**  
  The arrays we are merging are `[1, 2, 3]` and `[2, 5, 6]`.  
  The result of the merge is `[1, 2, 2, 3, 5, 6]`.

### Example 2
- **Input:** 
  - `nums1 = [1]`, `m = 1`
  - `nums2 = []`, `n = 0`
- **Output:** `nums1 = [1]`
- **Explanation:**  
  `nums2` is empty, so `nums1` remains `[1]`.

### Example 3
- **Input:** 
  - `nums1 = [0]`, `m = 0`
  - `nums2 = [1]`, `n = 1`
- **Output:** `nums1 = [1]`
- **Explanation:**  
  `nums1` has no initial elements ($m = 0$). `nums2` is copied directly into `nums1`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & The Three-Pointer Backward Approach
If we try to merge from the beginning (index 0), we would overwrite elements in `nums1` before we've had a chance to compare them.

Instead, notice that the **end of `nums1` is completely empty (filled with unused 0s)**!
- We can fill `nums1` **from right to left** (from the largest elements down to the smallest).
- Maintain three pointers:
  1. **`p1 = m - 1`:** Points to the largest remaining element in the valid part of `nums1`.
  2. **`p2 = n - 1`:** Points to the largest remaining element in `nums2`.
  3. **`p = m + n - 1`:** Points to the last available position in `nums1`.

#### Merging Steps:
- At each step, compare `nums1[p1]` and `nums2[p2]`:
  - Place whichever is larger into `nums1[p]`.
  - Decrement the respective pointer (`p1--` or `p2--`) and decrement `p--`.
- If `nums2` still has elements left after `p1 < 0`, copy the remaining `nums2` elements directly into `nums1`. (If `nums1` has leftovers, they are already in their correct places!).

---

### 2. Complete C++ Implementation (for `25.cpp`)

```cpp
#include<iostream>
using namespace std;

void merge(int nums1[], int m, int nums2[], int n) {
    int p1 = m - 1;         // Pointer for end of valid nums1 elements
    int p2 = n - 1;         // Pointer for end of nums2 elements
    int p = m + n - 1;      // Pointer for the very end of nums1 buffer

    while (p1 >= 0 && p2 >= 0) {
        if (nums1[p1] > nums2[p2]) {
            nums1[p] = nums1[p1];
            p1--;
        } else {
            nums1[p] = nums2[p2];
            p2--;
        }
        p--;
    }

    // Copy any remaining elements from nums2
    while (p2 >= 0) {
        nums1[p] = nums2[p2];
        p2--;
        p--;
    }
}

int main()
{
    int nums1[6] = {1, 2, 3, 0, 0, 0};
    int m = 3;
    int nums2[3] = {2, 5, 6};
    int n = 3;

    merge(nums1, m, nums2, n);

    cout << "Merged Array: ";
    for (int i = 0; i < m + n; i++) {
        cout << nums1[i] << " ";
    }
    cout << endl;

    return 0;
}
```

### 3. Step-by-Step Dry Run

`nums1 = [1, 2, 3, 0, 0, 0]` ($m = 3$, $p1 = 2$)  
`nums2 = [2, 5, 6]` ($n = 3$, $p2 = 2$)  
Target write index: $p = 5$

| Step | `nums1[p1]` | `nums2[p2]` | Comparison | Action | `nums1` State |
| :---: | :---: | :---: | :---: | :--- | :--- |
| **1** | 3 (`p1=2`) | 6 (`p2=2`) | $6 > 3$ | `nums1[5] = 6`, `p2--`, `p--` | `[1, 2, 3, 0, 0, 6]` |
| **2** | 3 (`p1=2`) | 5 (`p2=1`) | $5 > 3$ | `nums1[4] = 5`, `p2--`, `p--` | `[1, 2, 3, 0, 5, 6]` |
| **3** | 3 (`p1=2`) | 2 (`p2=0`) | $3 > 2$ | `nums1[3] = 3`, `p1--`, `p--` | `[1, 2, 3, 3, 5, 6]` |
| **4** | 2 (`p1=1`) | 2 (`p2=0`) | $2 \ge 2$ | `nums1[2] = 2`, `p2--`, `p--` | `[1, 2, 2, 3, 5, 6]` |

- `p2` becomes $-1$. Loop terminates.
- Final `nums1`: `[1, 2, 2, 3, 5, 6]`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(m + n)$  
  Each step places one element into its final position at index `p`. In the worst case, every element from both arrays is inspected once.
- **Space Complexity:** $O(1)$  
  The merge is performed directly in-place inside `nums1` without allocating any additional arrays.

---

### 5. Edge Cases
- **$n = 0$:** `nums2` has 0 elements. The `while` loops never run; `nums1` is already complete.
- **$m = 0$:** `nums1` has no initial elements. The second `while` loop cleanly copies all $n$ elements from `nums2` into `nums1`.

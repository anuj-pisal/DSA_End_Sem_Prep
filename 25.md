# Problem Title: Merge Sorted Array (LeetCode 88)

## Problem Statement
You are given two integer arrays `nums1` and `nums2`, sorted in **non-decreasing order**, and two integers `m` and `n`, representing the number of elements in `nums1` and `nums2` respectively.

Merge `nums2` into `nums1` as **one sorted array**.

> [!IMPORTANT]  
> The final sorted array should not be returned by the function, but instead be stored inside the array `nums1`. To accommodate this, `nums1` has a total length of $m + n$, where the first $m$ elements denote the elements that should be merged, and the last $n$ elements are set to `0` as placeholders and should be overwritten.

---

## Sample Examples

### Example 1
- **Input:** 
  - `nums1 = [1, 2, 3, 0, 0, 0]`, `m = 3`
  - `nums2 = [2, 5, 6]`, `n = 3`
- **Output:** `Merged : 1 2 2 3 5 6 `
- **Explanation:**  
  The arrays we are merging are `[1, 2, 3]` and `[2, 5, 6]`.  
  The result of the merge is `[1, 2, 2, 3, 5, 6]`.

### Example 2
- **Input:** 
  - `nums1 = [1]`, `m = 1`
  - `nums2 = []`, `n = 0`
- **Output:** `Merged : 1 `
- **Explanation:**  
  `nums2` is empty, so `nums1` remains `[1]`.

### Example 3
- **Input:** 
  - `nums1 = [0]`, `m = 0`
  - `nums2 = [1]`, `n = 1`
- **Output:** `Merged : 1 `
- **Explanation:**  
  `nums1` has no initial elements ($m = 0$). `nums2` is copied directly into `nums1`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & The Three-Pointer Backward Approach
If we try to merge from the beginning (index 0), we would overwrite elements in `nums1` before we've had a chance to compare them.

Instead, notice that the **end of `nums1` is completely empty (filled with unused 0s)**!
- We can fill `nums1` **from right to left** (from the largest elements down to the smallest).
- Maintain three pointers:
  1. **`i = m - 1`:** Points to the largest remaining element in the valid part of `nums1`.
  2. **`j = n - 1`:** Points to the largest remaining element in `nums2`.
  3. **`index = (m + n) - 1`:** Points to the last available position in `nums1`.

#### Merging Steps:
- At each step, compare `nums1[i]` and `nums2[j]`:
  - If `nums1[i] > nums2[j]`, place `nums1[i]` at `nums1[index]`, and decrement `i` and `index`.
  - Else, place `nums2[j]` at `nums1[index]`, and decrement `j` and `index`.
- If `nums2` still has elements left after `i < 0`, copy the remaining `nums2` elements directly into `nums1`. (If `nums1` has leftovers, they are already in their correct places!).

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
#include<fstream>
using namespace std;

void merge(int nums1[], int m, int nums2[], int n) {
    int index = (m+n) - 1;
    int i=m-1, j=n-1;
    
    while(i >= 0 && j >= 0) {
        if(nums1[i] > nums2[j]) {
            nums1[index--] = nums1[i--];
        }
        else {
            nums1[index--] = nums2[j--];
        }
    }

    while(j >= 0) {
        nums1[index--] = nums2[j--];
    }

    cout << "Merged : ";
    for(int k=0; k<(m+n); k++) {
        cout << nums1[k] << " "; 
    }

}

int main()
{
    int nums1[] = {1,2,3,0,0,0};
    int nums2[] = {2,5,6};
    int m = 3, n = 3;
    merge(nums1, m, nums2, n);
    return 0;
}
```

1. **Pointer Setup**:
   - `index = (m + n) - 1`: Starts writing at the last slot of `nums1`.
   - `i = m - 1`: Starts comparing from the end of `nums1`'s valid numbers.
   - `j = n - 1`: Starts comparing from the end of `nums2`.
2. **Comparison Loop (`while (i >= 0 && j >= 0)`)**:
   - Compares `nums1[i]` with `nums2[j]`.
   - Writes the larger value into `nums1[index]` and decrements the respective pointers using post-decrement (`index--`, `i--`, or `j--`).
3. **Leftover Loop (`while (j >= 0)`)**:
   - If `nums2` still has remaining elements after exhausting all of `nums1`'s elements, copies them directly into `nums1`.
4. **Output Display**:
   - Loops from `k = 0` to `m + n - 1` and prints all merged elements.

---

### 3. Step-by-Step Dry Run

`nums1 = [1, 2, 3, 0, 0, 0]` ($m = 3$, $i = 2$)  
`nums2 = [2, 5, 6]` ($n = 3$, $j = 2$)  
Write index: `index = 5`

| Step | `nums1[i]` | `nums2[j]` | Comparison | Action | `nums1` State |
| :---: | :---: | :---: | :---: | :--- | :--- |
| **1** | 3 (`i=2`) | 6 (`j=2`) | $6 > 3$ | `nums1[5] = 6`, `j--`, `index--` | `[1, 2, 3, 0, 0, 6]` |
| **2** | 3 (`i=2`) | 5 (`j=1`) | $5 > 3$ | `nums1[4] = 5`, `j--`, `index--` | `[1, 2, 3, 0, 5, 6]` |
| **3** | 3 (`i=2`) | 2 (`j=0`) | $3 > 2$ | `nums1[3] = 3`, `i--`, `index--` | `[1, 2, 3, 3, 5, 6]` |
| **4** | 2 (`i=1`) | 2 (`j=0`) | $2 \ge 2$ | `nums1[2] = 2`, `j--`, `index--` | `[1, 2, 2, 3, 5, 6]` |

- `j` becomes $-1$. Loop terminates.
- Final `nums1`: `[1, 2, 2, 3, 5, 6]`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(m + n)$  
  Each iteration moves either pointer `i` or `j` down by 1, placing one element into its final position. The total number of steps is at most $m + n$.
- **Space Complexity:** $O(1)$  
  The merge is performed directly in-place inside `nums1` without allocating any additional arrays.

---

### 5. Edge Cases
- **$n = 0$:** `nums2` has 0 elements. The `while` loops never run; `nums1` is already complete.
- **$m = 0$:** `nums1` has no initial elements. The second `while` loop cleanly copies all $n$ elements from `nums2` into `nums1`.

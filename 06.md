# Problem Title: Find K-th Character in String Game I (LeetCode 3304)

## Problem Statement
Alice and Bob are playing a game. Initially, Alice starts with a string containing a single character:
$$\text{word} = \text{"a"}$$

In each turn, a new string is generated by shifting every character of `word` to the **next character** in the English alphabet (with `'z'` wrapping around to `'a'`). This new string is then **appended** to `word`.

The game continues until the string has at least $k$ characters.

Given an integer $k$ ($k \ge 1$), find and return the **$k$-th character** of the final string (using 1-based indexing).

---

## Sample Examples

### Example 1
- **Input:** `k = 5`
- **Output:** `5th char is : b`
- **Explanation:**
  - **Start:** `word = "a"` (length = 1)
  - **Round 1:** Next characters of `"a"` $\rightarrow$ `"b"`.  
    Append to word $\rightarrow$ `word = "ab"` (length = 2)
  - **Round 2:** Next characters of `"ab"` $\rightarrow$ `"bc"`.  
    Append to word $\rightarrow$ `word = "abbc"` (length = 4)
  - **Round 3:** Next characters of `"abbc"` $\rightarrow$ `"bccd"`.  
    Append to word $\rightarrow$ `word = "abbcbccd"` (length = 8)
  - Length is now $8 \ge 5$. The 5th character (1-indexed) is `'b'`.

### Example 2
- **Input:** `k = 10`
- **Output:** `10th char is : c`
- **Explanation:**
  - Round 3 gave length 8: `"abbcbccd"`.
  - **Round 4:** Next characters of `"abbcbccd"` are `"bccdcdee"`.  
    Append $\rightarrow$ `"abbcbccdbccdcdee"` (length = 16).
  - Counting to index 10 (1-based):
    - `1: a, 2: b, 3: b, 4: c, 5: b, 6: c, 7: c, 8: d, 9: b, 10: c`  
    The 10th character is `'c'`.

### Example 3
- **Input:** `k = 1`
- **Output:** `1st char is : a`
- **Explanation:** The starting string `"a"` already has length 1. The 1st character is `'a'`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
In each step, the length of the string **doubles**:
- Round 0: length 1 (`"a"`)
- Round 1: length 2 (`"ab"`)
- Round 2: length 4 (`"abbc"`)
- Round 3: length 8 (`"abbcbccd"`)
- Round 4: length 16 (`"abbcbccdbccdcdee"`)

Since $k$ is given, we can simulate this doubling process:
1. Start with `"a"`.
2. As long as the string length is smaller than $k$:
   - For each character in the current string, calculate its next character:
     - If the character is `'z'`, wrap around to `'a'`.
     - Otherwise, take `ch + 1` (e.g. `'a'` becomes `'b'`, `'b'` becomes `'c'`).
   - Append all these newly shifted characters to the end of the string.
3. Once the string length reaches or exceeds $k$, the answer is at index `k - 1` (since C++ strings are 0-indexed).

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

char findKthChar(string str, int k) {
    int len = str.length();
    if(k <= len)
        return str[k-1];
    for(int i=0; i<len; i++) {
        char ch = str[i] == 'z' ? 'a' : (char)(str[i] + 1);
        str += ch;
    }
    return findKthChar(str, k);
}

int main()
{
    int k;
    cout << "Enter k : ";
    cin >> k;
    cout << k << "th char is : " << findKthChar("a", k);
    return 0;
}
```

1. **`findKthChar(string str, int k)` Function**:
   - `int len = str.length();` gets the current length of string `str`.
   - `if (k <= len) return str[k-1];`  
     This is the **base case**. If the string is already long enough to contain the $k$-th character, we return it immediately at index `k - 1`.
   - `for (int i = 0; i < len; i++)`:
     - Reads each character from index 0 to `len - 1`.
     - `char ch = str[i] == 'z' ? 'a' : (char)(str[i] + 1);` creates the successor character.
     - `str += ch;` appends the successor character to the string.
   - `return findKthChar(str, k);`:
     - Calls itself recursively with the newly doubled string.
2. **`main()` Function**:
   - Reads integer `k` from input.
   - Calls `findKthChar("a", k)` starting with `"a"`.
   - Displays the result.

---

### 3. Step-by-Step Execution Walkthrough for $k = 3$

1. **Call 1:** `findKthChar("a", 3)`
   - `len = 1`. Is `3 <= 1`? No.
   - Loop `i = 0`: `str[0] = 'a' \rightarrow ch = 'b'`. Appends `'b'`.
   - `str` becomes `"ab"`.
   - Recursive call: `findKthChar("ab", 3)`.

2. **Call 2:** `findKthChar("ab", 3)`
   - `len = 2`. Is `3 <= 2`? No.
   - Loop `i = 0`: `str[0] = 'a' \rightarrow ch = 'b'`. Appends `'b'`.
   - Loop `i = 1`: `str[1] = 'b' \rightarrow ch = 'c'`. Appends `'c'`.
   - `str` becomes `"abbc"`.
   - Recursive call: `findKthChar("abbc", 3)`.

3. **Call 3:** `findKthChar("abbc", 3)`
   - `len = 4`. Is `3 <= 4`? **Yes!**
   - Returns `str[3 - 1] = str[2] = 'b'`.

**Output:** `3th char is : b`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(k)$  
  The string doubles each round ($1, 2, 4, 8, \dots, 2^{\lceil \log_2 k \rceil}$). The total characters created and copied sum to $1 + 2 + 4 + \dots + 2k \le 4k = O(k)$.
- **Space Complexity:** $O(k)$  
  Memory needed to store the generated string of length up to $2k$, plus the recursion stack of depth $O(\log_2 k)$.

---

### 5. Edge Cases
- **$k = 1$:** The base condition `k <= len` triggers immediately on the first call, returning `str[0] = 'a'`.
- **Character wrap-around:** The ternary condition handles `'z' \rightarrow 'a'` safely.

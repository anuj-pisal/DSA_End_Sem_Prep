# Problem Title: Return the Column Index with Maximum Sum in a 2D Matrix

## Problem Statement
Given a 2D matrix `mat` of integers with `rows` rows and `cols` columns, find the **0-indexed column** that has the **maximum sum of elements**, along with the sum itself.

Output the result in the format `[maxCol, maxSum]`.

---

## Sample Examples

### Example 1
- **Input Matrix:**
  ```text
  [
    [34,  1,  4],
    [ 3,  4,  2],
    [ 3, 66,  4],
    [23, 44, 32]
  ]
  ```
- **Output:** `[1, 115]`
- **Explanation:**  
  Summing each column vertically:
  - Column 0: $34 + 3 + 3 + 23 = 63$
  - Column 1: $1 + 4 + 66 + 44 = 115$
  - Column 2: $4 + 2 + 4 + 32 = 42$  
  Column 1 has the maximum sum ($115$).

### Example 2
- **Input Matrix:**
  ```text
  [
    [10, 5],
    [20, 2]
  ]
  ```
- **Output:** `[0, 30]`
- **Explanation:**  
  Column 0 sum is $10 + 20 = 30$. Column 1 sum is $5 + 2 = 7$. Column 0 has the larger sum.

### Example 3
- **Input Matrix:**
  ```text
  [
    [-1, -5],
    [-2, -3]
  ]
  ```
- **Output:** `[0, -3]`
- **Explanation:**  
  Column 0 sum is $-3$, Column 1 sum is $-8$. Since $-3 > -8$, Column 0 is the maximum.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
In a standard row-wise traversal, the outer loop iterates over rows and the inner loop iterates over columns.

For a **column-wise sum**, we simply flip the loop hierarchy:
1. The **outer loop** iterates over each column `j` from $0$ to $\text{cols} - 1$.
2. The **inner loop** iterates vertically through each row `i` from $0$ to $\text{rows} - 1$, accumulating `mat[i][j]`.
3. Compare the sum of each column against `maxSum`:
   - Initialize `maxSum` with the sum of Column 0 and set `maxCol = 0`.
   - If any subsequent column sum `curr > maxSum`, update `maxSum = curr` and `maxCol = j`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int mat[][3] = {{34,1,4}, {3,4,2}, {3,66,4}, {23,44,32}};
    int cols = 3, rows = 4; 
    int maxCol = 0;
    int maxSum = 0;

    for(int i=0; i<rows; i++) {
        maxSum += mat[i][0];
    }
    
    for(int j=1; j<cols; j++) {
        int curr = 0;
        for(int i=0; i<rows; i++) {
            curr += mat[i][j];
        }
        if(curr > maxSum) {
            maxSum = curr;
            maxCol = j;
        }
    }

    cout << "[" << maxCol << ", " << maxSum << "]";

    return 0;
}
```

1. **Summing Column 0 (Baseline)**:
   - `for(int i=0; i<rows; i++) maxSum += mat[i][0];`  
     Vertical traversal along column 0:
     $34 + 3 + 3 + 23 = 63$.
   - Sets `maxSum = 63` and `maxCol = 0`.
2. **Checking Remaining Columns (`j = 1` to `cols - 1`)**:
   - `j = 1` (Column 1):
     - `curr = mat[0][1] + mat[1][1] + mat[2][1] + mat[3][1] = 1 + 4 + 66 + 44 = 115`.
     - Since $115 > 63$, update `maxSum = 115` and `maxCol = 1`.
   - `j = 2` (Column 2):
     - `curr = mat[0][2] + mat[1][2] + mat[2][2] + mat[3][2] = 4 + 2 + 4 + 32 = 42`.
     - $42 < 115$, no change.
3. **Display**:
   - Prints `[1, 115]`.

---

### 3. Step-by-Step Dry Run

Matrix ($4 \times 3$):

```
Col 0   Col 1   Col 2
  34       1       4
   3       4       2
   3      66       4
  23      44      32
```

| Column `j` | Elements in Column | Column Sum (`curr`) | Comparison (`curr > maxSum`) | `maxCol` | `maxSum` |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **0** | `34, 3, 3, 23` | 63 | Baseline | 0 | 63 |
| **1** | `1, 4, 66, 44` | 115 | $115 > 63$ (**True**) | **1** | **115** |
| **2** | `4, 2, 4, 32` | 42 | $42 > 115$ (False) | **1** | **115** |

Final Result: **`[1, 115]`**.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\text{cols} \times \text{rows})$  
  Every cell in the matrix is accessed once, resulting in linear time with respect to the total number of cells.
- **Space Complexity:** $O(1)$  
  Constant auxiliary space used for sum variables.

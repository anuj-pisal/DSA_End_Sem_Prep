# Problem Title: Remove Duplicates from Sorted Array (LeetCode 26)

## Problem Statement
Given an integer array `arr` sorted in **non-decreasing (ascending) order**, remove the duplicates **in-place** such that each unique element appears only once. The relative order of the elements should be maintained.

Return the number of unique elements, denoted as $k$.

After removing duplicates:
- The first $k$ elements of `arr` must contain the unique elements in their original order.
- The remaining elements beyond index $k - 1$ do not matter.

> [!IMPORTANT]  
> The removal must be done **in-place** using $O(1)$ extra memory. You cannot allocate a new array to copy unique elements.

---

## Sample Examples

### Example 1
- **Input:** `arr = [1, 1, 2]`
- **Output:** 
  - Number of unique elements: `k = 2`
  - Modified array: `[1, 2, _]`
- **Explanation:**  
  The unique elements are `1` and `2`. They occupy the first 2 positions of the array.

### Example 2
- **Input:** `arr = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`
- **Output:** 
  - Number of unique elements: `k = 5`
  - Modified array: `[0, 1, 2, 3, 4, _, _, _, _, _]`
- **Explanation:**  
  The five unique elements are `0, 1, 2, 3, 4`. They are placed in the first 5 slots of the array.

### Example 3
- **Input:** `arr = [7]`
- **Output:**
  - Number of unique elements: `k = 1`
  - Modified array: `[7]`
- **Explanation:** An array with a single element has no duplicates.

---

## Detailed Solution (In Simple English)

### 1. Intuition & The Two-Pointer Approach
Because the input array is already **sorted**, all identical duplicate numbers are grouped together right next to each other!

This enables the **Two-Pointer Technique**:
- **Slow Pointer (`i`):** Marks the position of the last placed unique element in the front portion of the array. Starts at index `0`.
- **Fast Pointer (`j`):** Scans forward through the array from index `1` to `len - 1` looking for the next *new* unique number.

Whenever the fast pointer `j` finds an element that is **different** from the element at `arr[i]`:
1. Increment the slow pointer: `i++` (make room for the new unique value).
2. Copy the new unique value into that slot: `arr[i] = arr[j]`.
3. If `arr[j] == arr[i]`, it is a duplicate, so we simply ignore it and keep moving `j` forward.

When `j` finishes scanning, the total count of unique elements is `k = i + 1`.

---

### 2. Complete C++ Implementation (Completing `14.cpp`)

```cpp
#include<iostream>
using namespace std;

int removeDuplicates(int arr[], int n) {
    if (n == 0) return 0;

    int i = 0; // Slow pointer: points to the last unique element
    for (int j = 1; j < n; j++) { // Fast pointer: scans through array
        if (arr[j] != arr[i]) {
            i++;
            arr[i] = arr[j]; // Place the new unique element
        }
    }
    return i + 1; // Number of unique elements
}

int main()
{
    int arr[] = {0, 0, 1, 1, 1, 2, 2, 3, 3, 4};
    int n = sizeof(arr) / sizeof(arr[0]);

    cout << "Original Array: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    int k = removeDuplicates(arr, n);

    cout << "Number of unique elements: " << k << endl;
    cout << "Array after removing duplicates: ";
    for (int i = 0; i < k; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

### 3. Step-by-Step Execution Walkthrough

Input: `arr = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]` ($n = 10$)

- Initially: `i = 0` (`arr[i] = 0`).

| Fast Pointer `j` | `arr[j]` | Comparison (`arr[j] != arr[i]`) | Action | Array (first $i+1$ elements) |
| :---: | :---: | :---: | :--- | :--- |
| `j = 1` | `0` | $0 \ne 0$ (False) | Duplicate; skip. | `[0]` |
| `j = 2` | `1` | $1 \ne 0$ (**True**) | `i++` $\rightarrow i=1$; `arr[1] = 1` | `[0, 1]` |
| `j = 3` | `1` | $1 \ne 1$ (False) | Duplicate; skip. | `[0, 1]` |
| `j = 4` | `1` | $1 \ne 1$ (False) | Duplicate; skip. | `[0, 1]` |
| `j = 5` | `2` | $2 \ne 1$ (**True**) | `i++` $\rightarrow i=2$; `arr[2] = 2` | `[0, 1, 2]` |
| `j = 6` | `2` | $2 \ne 2$ (False) | Duplicate; skip. | `[0, 1, 2]` |
| `j = 7` | `3` | $3 \ne 2$ (**True**) | `i++` $\rightarrow i=3$; `arr[3] = 3` | `[0, 1, 2, 3]` |
| `j = 8` | `3` | $3 \ne 3$ (False) | Duplicate; skip. | `[0, 1, 2, 3]` |
| `j = 9` | `4` | $4 \ne 3$ (**True**) | `i++` $\rightarrow i=4$; `arr[4] = 4` | `[0, 1, 2, 3, 4]` |

- Loop finishes.
- Returns `k = i + 1 = 4 + 1 = 5`.
- Unique elements in the first 5 slots: `[0, 1, 2, 3, 4]`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  The fast pointer `j` visits each element from index 1 to $n - 1$ exactly once. Each check and possible assignment takes constant time $O(1)$.
- **Space Complexity:** $O(1)$  
  All modifications are made directly **in-place** inside the existing array using only two pointer variables (`i` and `j`). No auxiliary array or data structure is allocated.

---

### 5. Edge Cases
- **Empty Array ($n = 0$):** Handled by `if (n == 0) return 0;`.
- **Single Element ($n = 1$):** Loop from `j = 1` never runs; returns `1`.
- **All Elements Identical (e.g., `[1, 1, 1, 1]`):** `j` never triggers a difference; returns `k = 1` with `[1]`.
- **No Duplicates (e.g., `[1, 2, 3, 4]`):** Every element triggers an assignment; returns `k = 4` with the array unchanged.

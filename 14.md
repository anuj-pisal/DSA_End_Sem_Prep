# Problem Title: Remove Duplicates from Sorted Array (LeetCode 26)

## Problem Statement
Given an integer array `arr` sorted in **non-decreasing (ascending) order**, remove the duplicates **in-place** such that each unique element appears only once. The relative order of the elements must be kept the same.

In this implementation:
- All unique elements are shifted to the front of the array.
- The remaining positions up to the end of the array are padded with `0`.
- The final array is displayed.

---

## Sample Examples

### Example 1
- **Input Array:** `arr = [1, 1, 2, 2, 2, 2, 3, 3, 4]`
- **Output:** `1 2 3 4 0 0 0 0 0`
- **Explanation:**  
  The unique elements are `1, 2, 3, 4` (total 4 unique elements).  
  The first 4 spots of the array are filled with `1, 2, 3, 4`, and the remaining 5 positions are set to `0`.

### Example 2
- **Input Array:** `arr = [1, 1, 2]`
- **Output:** `1 2 0`
- **Explanation:**  
  There are 2 unique numbers (`1` and `2`). Index 0 gets `1`, index 1 gets `2`, and index 2 is zeroed out.

### Example 3
- **Input Array:** `arr = [5, 5, 5, 5]`
- **Output:** `5 0 0 0`
- **Explanation:**  
  Only a single unique number (`5`) exists. The rest of the 3 slots become `0`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
Because the input array is already **sorted**, duplicate numbers always appear right next to each other.

To filter out duplicates in a single pass:
- We can compare each element `arr[j]` with its immediate predecessor `arr[j - 1]`.
- If `arr[j] != arr[j - 1]`, that means `arr[j]` is a brand new unique number that we have not seen before!
- We use two pointers:
  - **`j` (Reader / Fast Pointer):** Scans every element from index `1` to `n - 1`.
  - **`i` (Writer / Slow Pointer):** Points to the next available position in the front of the array where the next unique number should be placed.
- Since `arr[0]` is always the first unique element, we start both `i` and `j` at index `1`.
- Whenever `arr[j] != arr[j - 1]`, we write `arr[i] = arr[j]` and increment `i++`.
- Finally, to clean up the trailing leftover slots from index `i` to `n - 1`, we fill them with `0`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int arr[] = {1,1,2,2,2,2,3,3,4};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    int i=1, j=1;
    while(j < n) {
        if(arr[j] != arr[j-1]) {
            arr[i] = arr[j];
            i++;
        }
        j++;
    }    

    while(i < n) arr[i++] = 0;

    for(int x : arr) {
        cout << x << " ";
    }

    return 0;
}
```

1. **Initialization**:
   - `int arr[] = {1,1,2,2,2,2,3,3,4};` with size `n = 9`.
   - `int i = 1, j = 1;`: The first element `arr[0]` (`1`) is already in its correct spot, so both pointers begin at index 1.
2. **First `while` Loop (Extracting Unique Elements)**:
   - `while (j < n)`:
     - `if (arr[j] != arr[j - 1])`: Compares current element with the previous element.
     - When a change is detected, `arr[i] = arr[j];` copies the new unique value to position `i`, and `i++` moves to the next write slot.
     - `j++`: Always advances the scan forward.
3. **Second `while` Loop (Padding with Zeroes)**:
   - `while (i < n) arr[i++] = 0;`: Fills all remaining elements from index `i` to `n - 1` with `0`.
4. **Display**:
   - Range-based for loop `for (int x : arr)` prints the modified array.

---

### 3. Step-by-Step Execution Walkthrough

Input: `arr = [1, 1, 2, 2, 2, 2, 3, 3, 4]` ($n = 9$)

| Step (`j`) | `arr[j]` | `arr[j-1]` | `arr[j] != arr[j-1]` | Action | Array State |
| :---: | :---: | :---: | :---: | :--- | :--- |
| **Start** | - | - | - | `i = 1, j = 1` | `[1, 1, 2, 2, 2, 2, 3, 3, 4]` |
| `j = 1` | 1 | 1 | False | Duplicate; skip | `[1, 1, 2, 2, 2, 2, 3, 3, 4]` |
| `j = 2` | 2 | 1 | **True** | `arr[1] = 2; i = 2` | `[1, 2, 2, 2, 2, 2, 3, 3, 4]` |
| `j = 3` | 2 | 2 | False | Duplicate; skip | `[1, 2, 2, 2, 2, 2, 3, 3, 4]` |
| `j = 4` | 2 | 2 | False | Duplicate; skip | `[1, 2, 2, 2, 2, 2, 3, 3, 4]` |
| `j = 5` | 2 | 2 | False | Duplicate; skip | `[1, 2, 2, 2, 2, 2, 3, 3, 4]` |
| `j = 6` | 3 | 2 | **True** | `arr[2] = 3; i = 3` | `[1, 2, 3, 2, 2, 2, 3, 3, 4]` |
| `j = 7` | 3 | 3 | False | Duplicate; skip | `[1, 2, 3, 2, 2, 2, 3, 3, 4]` |
| `j = 8` | 4 | 3 | **True** | `arr[3] = 4; i = 4` | `[1, 2, 3, 4, 2, 2, 3, 3, 4]` |

After first while loop: `i = 4`.  
The second while loop sets indices `4, 5, 6, 7, 8` to `0`:
Final Array: `[1, 2, 3, 4, 0, 0, 0, 0, 0]`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  - The first while loop runs $n - 1$ times.
  - The second while loop runs at most $n$ times.
  - Total operations = $(n - 1) + n = O(n)$, linear time.
- **Space Complexity:** $O(1)$  
  Operates completely in-place on the existing array without allocating any extra storage.

---

### 5. Edge Cases
- **Array with all identical elements:** e.g., `[2, 2, 2]`. The loop writes nothing; `i` remains 1; subsequent slots become `0` $\rightarrow$ `[2, 0, 0]`.
- **Array with no duplicates:** e.g., `[1, 2, 3]`. `arr[j] != arr[j-1]` is true at every step; array remains `[1, 2, 3]`.

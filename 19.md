# Problem Title: Find Majority Element from Array (LeetCode 169)

## Problem Statement
Given an array `arr` of size $n$, find the **majority element**.

The majority element is defined as the element that appears **more than $\lfloor n / 2 \rfloor$ times** in the array. You may assume that the majority element always exists in the array.

---

## Sample Examples

### Example 1
- **Input Array:** `arr = [2, 3, 3, 2, 3, 2, 2, 3, 3, 3]` ($n = 10$)
- **Output:** `Candidate with more than n/2 votes : 3`
- **Explanation:**  
  - Threshold $\lfloor n / 2 \rfloor = 10 / 2 = 5$.
  - Count of `2`: $4$ times
  - Count of `3`: $6$ times
  - Since $6 > 5$, `3` is the majority element.

### Example 2
- **Input Array:** `arr = [3, 2, 3]` ($n = 3$)
- **Output:** `Candidate with more than n/2 votes : 3`
- **Explanation:**  
  - Threshold $\lfloor 3 / 2 \rfloor = 1$.
  - Count of `3` is 2 ($2 > 1$). Hence, `3` is the majority element.

### Example 3
- **Input Array:** `arr = [7, 7, 7, 1, 2, 7, 7]` ($n = 7$)
- **Output:** `Candidate with more than n/2 votes : 7`
- **Explanation:**  
  `7` appears 5 times out of 7, easily exceeding the majority threshold.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach (Boyer-Moore Voting Algorithm)
A naive approach would be:
- Use a hash map / frequency array to count occurrences of each element ($O(n)$ space), or
- Sort the array and pick the middle element ($O(n \log n)$ time).

However, this solution uses an optimal **$O(n)$ time and $O(1)$ space** technique known as the **Boyer-Moore Voting Algorithm**:

#### The Election Analogy:
- Think of the numbers as votes for different candidates in an election.
- The majority element has **more than half** of all votes.
- If we pair up different candidates' votes and cancel them out against each other (one vote for Candidate A cancels one vote for Candidate B), the majority candidate will **always have surviving votes left over**!

#### Rules:
1. Maintain a candidate `cand` and a vote count `votes`.
2. Start by assuming `arr[0]` is the leading candidate with 1 vote.
3. For each subsequent element:
   - If it matches `cand`, increment `votes++`.
   - If it does not match `cand`, decrement `votes--` (canceling one vote).
   - If votes drop below zero, the current candidate is eliminated, and we elect the current element as the new `cand` with `votes = 1`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int arr[] = {2,3,3,2,3,2,2,3,3,3};
    int cand = arr[0];
    int votes = 1;
    int n = sizeof(arr) / sizeof(arr[0]);

    for(int i=1; i<n; i++) {
        if(arr[i] == cand) {
            votes++;
        }
        else {
            votes--;
        }
        if(votes < 0) {
            votes = 1;
            cand = arr[i];
        }
    }

    cout << "Candidate with more than n/2 votes : " << cand;
    return 0;
}
```

1. **Candidate & Counter Setup**:
   - `int cand = arr[0];` sets the initial candidate to `arr[0] = 2`.
   - `int votes = 1;` initializes the vote tally.
2. **The Voting Loop (`for (int i = 1; i < n; i++)`)**:
   - `if (arr[i] == cand) votes++;`: Vote matches candidate, so strength increases.
   - `else votes--;`: Opposite vote, canceling out.
   - `if (votes < 0)`:
     - When opposition overwhelms the current candidate, we switch candidates:
     - `cand = arr[i];`
     - `votes = 1;`
3. **Result Output**:
   - At the end of the array, `cand` holds the majority element.

### 3. Step-by-Step Execution Walkthrough

Array: `[2, 3, 3, 2, 3, 2, 2, 3, 3, 3]`

| Index `i` | Element `arr[i]` | Action | `votes` | `cand` |
| :---: | :---: | :--- | :---: | :---: |
| **Start** | `arr[0] = 2` | Initialize candidate | 1 | 2 |
| `i = 1` | 3 | $3 \ne 2 \rightarrow$ `votes--` | 0 | 2 |
| `i = 2` | 3 | $3 \ne 2 \rightarrow$ `votes--` (-1) $\rightarrow$ votes < 0: reset | 1 | **3** |
| `i = 3` | 2 | $2 \ne 3 \rightarrow$ `votes--` | 0 | 3 |
| `i = 4` | 3 | $3 == 3 \rightarrow$ `votes++` | 1 | 3 |
| `i = 5` | 2 | $2 \ne 3 \rightarrow$ `votes--` | 0 | 3 |
| `i = 6` | 2 | $2 \ne 3 \rightarrow$ `votes--` (-1) $\rightarrow$ votes < 0: reset | 1 | **2** |
| `i = 7` | 3 | $3 \ne 2 \rightarrow$ `votes--` | 0 | 2 |
| `i = 8` | 3 | $3 \ne 2 \rightarrow$ `votes--` (-1) $\rightarrow$ votes < 0: reset | 1 | **3** |
| `i = 9` | 3 | $3 == 3 \rightarrow$ `votes++` | 2 | **3** |

Final Majority Element: **`3`**.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  The algorithm makes a single linear pass over the array of size $n$.
- **Space Complexity:** $O(1)$  
  Only uses two integer tracking variables (`cand`, `votes`), taking constant extra space.

---

### 5. Edge Cases & Verification
- **Majority Element Guaranteed:** The Boyer-Moore algorithm guarantees the correct result in $O(1)$ space if a majority element ($> n/2$) exists.
- **Verification Pass (if existence is not guaranteed):** If an array might NOT have a majority element, a quick second pass counting occurrences of `cand` can confirm if its count truly exceeds $n / 2$.

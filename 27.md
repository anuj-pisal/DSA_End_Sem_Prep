# Problem Title: Relative Ranks (LeetCode 506)

## Problem Statement
You are given an integer array `arr` of size $n$, where `arr[i]` is the score of the $i$-th athlete in a competition. All scores are guaranteed to be unique.

Athletes are ranked based on their scores from highest to lowest:
- **1st Place (Highest score):** `"GOLD Medal"`
- **2nd Place:** `"SILVER Medal"`
- **3rd Place:** `"BRONZE Medal"`
- **4th Place onwards:** Their placement number as a string (`"4"`, `"5"`, `"6"`, etc.)

Return/display an array where the $i$-th position contains the rank corresponding to the $i$-th athlete's original position.

---

## Sample Examples

### Example 1
- **Input Scores:** `arr = [1, 4, 5, 2, 3]`
- **Output:**
  ```text
  5	SILVER Medal	GOLD Medal	4	BRONZE Medal	
  ```
- **Explanation:**  
  - Athlete 2 has score `5` (1st place) $\rightarrow$ `"GOLD Medal"`
  - Athlete 1 has score `4` (2nd place) $\rightarrow$ `"SILVER Medal"`
  - Athlete 4 has score `3` (3rd place) $\rightarrow$ `"BRONZE Medal"`
  - Athlete 3 has score `2` (4th place) $\rightarrow$ `"4"`
  - Athlete 0 has score `1` (5th place) $\rightarrow$ `"5"`  
  Placing these ranks into the athletes' original indices yields `[5, SILVER Medal, GOLD Medal, 4, BRONZE Medal]`.

### Example 2
- **Input Scores:** `arr = [10, 3, 8, 9, 4]`
- **Output:**
  ```text
  GOLD Medal	5	BRONZE Medal	SILVER Medal	4	
  ```
- **Explanation:**  
  - `10` $\rightarrow$ 1st (Gold)
  - `9` $\rightarrow$ 2nd (Silver)
  - `8` $\rightarrow$ 3rd (Bronze)
  - `4` $\rightarrow$ 4th
  - `3` $\rightarrow$ 5th

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
The challenge is that sorting the scores changes their positions, but the final output must preserve the **original index order** of each athlete.

To solve this:
1. **Remember Original Positions:**  
   Before sorting, use a map `map<int, int> m` where `m[score] = original_index`.
2. **Sort Scores:**  
   Sort the array in ascending order. The largest score will be at index `n - 1`, the second largest at `n - 2`, and so forth.
3. **Assign Ranks in Descending Order:**  
   Iterate backwards from `n - 1` down to `0`:
   - Identify which athlete had this score: `index = m[arr[i]]`.
   - Track rank counter `curr` (starts at 1):
     - `curr == 1` $\rightarrow$ `"GOLD Medal"`
     - `curr == 2` $\rightarrow$ `"SILVER Medal"`
     - `curr == 3` $\rightarrow$ `"BRONZE Medal"`
     - `curr >= 4` $\rightarrow$ `to_string(curr)`
   - Store the award string at `res[index]`.
4. Print the final `res` array.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
#include<map>
using namespace std;

void sort(int arr[], int n) {
    for(int i=1; i<n; i++) {
        for(int j=0; j<n-i; j++) {
            if(arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
            }
        }
    }
}

int main()
{
    map<int, int> m;
    int arr[] = {1,4,5,2,3};
    int n = 5;

    for(int i=0; i<n; i++) {
        m[arr[i]] = i;
    }

    sort(arr, n);
    
    string res[n];
    int curr = 1;

    for(int i=n-1; i>=0; i--) {
        int index = m[arr[i]];
        if(curr == 1) {
            res[index] = "GOLD Medal";
        }
        else if(curr == 2) {
            res[index] = "SILVER Medal";
        }
        else if(curr == 3) {
            res[index] = "BRONZE Medal";
        }
        else {
            res[index] = to_string(curr); 
        }

        curr++;
    }

    for(string s : res) {
        cout << s << "\t";
    }

    return 0;
}
```

1. **Mapping Indices**:
   - `m[1] = 0`, `m[4] = 1`, `m[5] = 2`, `m[2] = 3`, `m[3] = 4`.
2. **Bubble Sort**:
   - `sort(arr, n)` sorts `arr` into `[1, 2, 3, 4, 5]`.
3. **Assigning Ranks Backward**:
   - Starts at `i = 4` (`arr[4] = 5`), gets `index = m[5] = 2`, assigns `"GOLD Medal"` to `res[2]`.
   - `i = 3` (`arr[3] = 4`), gets `index = m[4] = 1`, assigns `"SILVER Medal"` to `res[1]`.
   - `i = 2` (`arr[2] = 3`), gets `index = m[3] = 4`, assigns `"BRONZE Medal"` to `res[4]`.
   - `i = 1` (`arr[1] = 2`), gets `index = m[2] = 3`, assigns `"4"` to `res[3]`.
   - `i = 0` (`arr[0] = 1`), gets `index = m[1] = 0`, assigns `"5"` to `res[0]`.
4. **Output Generation**:
   - Loops through `res` and displays the rank for each original position.

### 3. Step-by-Step Dry Run

Scores: `[1, 4, 5, 2, 3]`

| `curr` (Rank) | Score `arr[i]` | Original Index (`m[score]`) | Rank Assigned | `res` Array State |
| :---: | :---: | :---: | :---: | :--- |
| **1** | 5 | 2 | "GOLD Medal" | `[?, ?, "GOLD Medal", ?, ?]` |
| **2** | 4 | 1 | "SILVER Medal" | `[?, "SILVER Medal", "GOLD Medal", ?, ?]` |
| **3** | 3 | 4 | "BRONZE Medal" | `[?, "SILVER Medal", "GOLD Medal", ?, "BRONZE Medal"]` |
| **4** | 2 | 3 | "4" | `[?, "SILVER Medal", "GOLD Medal", "4", "BRONZE Medal"]` |
| **5** | 1 | 0 | "5" | `["5", "SILVER Medal", "GOLD Medal", "4", "BRONZE Medal"]` |

### 4. Complexity Analysis

- **Time Complexity:**
  - Map insertion: $O(n \log n)$ using `std::map`.
  - Sorting: $O(n^2)$ using Bubble Sort (or $O(n \log n)$ with `std::sort`).
  - Rank assignment: $O(n \log n)$ map lookups.
  - Overall Time: $O(n^2)$ with the provided bubble sort.
- **Space Complexity:** $O(n)$  
  - Map of size $n$ and string result array of size $n$.

---

### 5. Edge Cases
- **Fewer than 3 athletes ($n < 3$):** If $n = 1$, only Gold is awarded. If $n = 2$, only Gold and Silver are awarded. The `if-else` cascade handles this safely.

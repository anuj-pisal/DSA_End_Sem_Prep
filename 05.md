# Problem Title: Find Trailing Zeroes in Factorial (LeetCode 172)

## Problem Statement
Given an integer $n$, calculate and return the number of **trailing zeroes** in $n!$ (factorial of $n$).

A trailing zero is a digit `0` that appears at the very end of a number (e.g., $120$ has 1 trailing zero, and $1000$ has 3 trailing zeroes).

> [!NOTE]  
> The challenge is to calculate the trailing zeroes without directly computing $n!$, because factorials grow overwhelmingly large and will quickly overflow standard numeric data types even for modest inputs like $n = 20$.

---

## Sample Examples

### Example 1
- **Input:** `n = 5`
- **Output:** `No. of trailing zeros of 5! is : 1`
- **Explanation:**  
  $$5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$$  
  The number $120$ ends with one zero. Thus, output is `1`.

### Example 2
- **Input:** `n = 25`
- **Output:** `No. of trailing zeros of 25! is : 6`
- **Explanation:**  
  Numbers contributing factors of 5 up to 25 are:
  - Multiples of 5: $5, 10, 15, 20, 25 \rightarrow$ five factors of 5.
  - Multiples of $5^2 = 25$: $25$ gives an **extra** factor of 5.  
  Total factors of 5 = $5 + 1 = 6$ zeroes.

### Example 3
- **Input:** `n = 0`
- **Output:** `No. of trailing zeros of 0! is : 0`
- **Explanation:**  
  $0! = 1$, which has 0 trailing zeroes.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Mathematical Logic (Legendre's Formula)

Where does a trailing zero come from?
- A trailing zero (`10`) is produced by multiplying a prime factor **2** and a prime factor **5** ($2 \times 5 = 10$).
- In any factorial $n! = 1 \times 2 \times 3 \times \dots \times n$:
  - Even numbers appear every 2 steps ($2, 4, 6, 8, 10, \dots$), so there is an abundant supply of 2s.
  - Multiples of 5 appear only every 5 steps ($5, 10, 15, 20, \dots$), so 5 is the **limiting factor**.
- Therefore, the number of trailing zeroes is simply equal to the **total number of times 5 appears as a prime factor** in the product $1 \times 2 \times \dots \times n$.

To count how many times 5 appears:
1. Every multiple of 5 gives at least one factor of 5: $\lfloor n / 5 \rfloor$.
2. Every multiple of $25 = 5^2$ gives a second factor of 5: $\lfloor n / 25 \rfloor$.
3. Every multiple of $125 = 5^3$ gives a third factor of 5: $\lfloor n / 125 \rfloor$, and so on.

$$\text{Total zeroes} = \left\lfloor \frac{n}{5} \right\rfloor + \left\lfloor \frac{n}{25} \right\rfloor + \left\lfloor \frac{n}{125} \right\rfloor + \dots$$

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int trailingZeros(int n) {
    if(n < 5) 
        return 0;
    return (n/5) + trailingZeros(n/5);
}

int main()
{
    int n;
    cout << "Enter n : " << endl;
    cin >> n;
    cout << "No. of trailing zeros of " << n << "! is : " << trailingZeros(n) << endl;
    return 0;
}
```

The function `trailingZeros(int n)` elegantly implements this formula recursively:
1. **Base Case:**
   - `if (n < 5) return 0;`  
     If $n < 5$, no number from 1 to $n$ can be divided by 5. So there are 0 trailing zeroes.
2. **Recursive Step:**
   - `return (n / 5) + trailingZeros(n / 5);`  
     - `n / 5` counts all single factors of 5.
     - Calling `trailingZeros(n / 5)` computes $\lfloor (n/5) / 5 \rfloor = \lfloor n / 25 \rfloor$, and then $\lfloor n / 125 \rfloor$, and so on, accumulating all higher powers of 5 automatically!

---

### 3. Step-by-Step Execution Walkthrough for $n = 100$

Let's trace `trailingZeros(100)`:
1. `trailingZeros(100)`:
   - `100 / 5 = 20`
   - Calls `trailingZeros(20)`
2. `trailingZeros(20)`:
   - `20 / 5 = 4`
   - Calls `trailingZeros(4)`
3. `trailingZeros(4)`:
   - Hits base case ($4 < 5$) $\rightarrow$ returns `0`.

Now combining results:
- `trailingZeros(20)` returns $4 + 0 = 4$
- `trailingZeros(100)` returns $20 + 4 = 24$

**Result:** $100!$ has **24 trailing zeroes** (computed instantaneously without ever having to multiply 100 numbers).

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\log_5 n)$  
  In each recursive call, $n$ is divided by 5. The total number of operations is proportional to the number of powers of 5 up to $n$, which is $\log_5 n$. For example, even for $n = 1,000,000$, it takes only about 8 calls!
- **Space Complexity:** $O(\log_5 n)$  
  Memory on the recursion call stack, which is at most $O(\log_5 n)$ stack frames.

---

### 5. Edge Cases
- **$n < 5$ ($n = 0, 1, 2, 3, 4$):** Correctly caught by `if (n < 5) return 0;`.
- **Large $n$:** No risk of numeric overflow during the factorial calculation because the factorial itself is never computed!

# Problem Title: Sorting an Array using Insertion Sort

## Problem Statement
Given an unsorted array of integers, sort the array elements in **ascending order** using the **Insertion Sort** algorithm.

---

## Sample Examples

### Example 1
- **Input Array:** `[32, 11, 5, 65, 97, 31]`
- **Output:**
  ```text
  Before Sorting : 
  val : 	32		11		5		65		97		31		

  After Sorting : 
  val : 	5		11		31		32		65		97		
  ```
- **Explanation:**  
  Each element from index 1 to 5 is picked one by one and inserted into its correct position among the already-sorted elements to its left.

### Example 2
- **Input Array:** `[12, 11, 13, 5, 6]`
- **Output:**
  ```text
  After Sorting : 
  val : 	5		6		11		12		13		
  ```
- **Explanation:**  
  The numbers are rearranged into ascending order by shifting larger elements one position to the right and inserting the current card in the opening.

---

## Detailed Solution (In Simple English)

### 1. Intuition & The "Playing Cards" Analogy
Think about how you sort playing cards in your hand:
- You hold a few cards that are already sorted.
- You pick up a new card from the table (`temp`).
- You look from right to left across your sorted cards:
  - If a card in your hand is bigger than your new card, you shift it one slot to the right.
  - As soon as you find a card that is smaller (or reach the left end), you **insert** your new card into that empty slot!

In an array:
- We conceptually split the array into two parts:
  - Left side: **Sorted subarray** (starts with just the first element `arr[0]`).
  - Right side: **Unsorted subarray** (elements from index `1` to `n - 1`).
- We take elements from the unsorted part one by one and insert them into their correct spot in the sorted part.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

void display(int arr[], int len) {
    cout << "val : \t";
    for(int i=0; i<len; i++) {
        cout << arr[i] << "\t\t";
    }
    cout << endl;
}

int main()
{
    int arr[] = {32,11,5,65,97,31};
    int n = sizeof(arr) / sizeof(arr[0]);

    cout << "Before Sorting : \n";
    display(arr, n);
    
    for(int i=1; i<n; i++) {
        int temp = arr[i];
        int j = i-1;
        while(j >= 0 && arr[j] > temp) {
            arr[j+1] = arr[j];
            j--;
        } 
        arr[j+1] = temp;
    }

    cout << "\nAfter Sorting : \n";
    display(arr, n);

    return 0;
}
```

1. **Outer Loop (`for(int i = 1; i < n; i++)`)**:  
   Iterates from the second element (index 1) to the end. The element `arr[i]` is the "card" we want to insert, saved in `int temp = arr[i]`.
2. **Inner Pointer (`int j = i - 1`)**:  
   Starts comparing backwards from the element immediately before `i`.
3. **Shifting Elements (`while(j >= 0 && arr[j] > temp)`)**:  
   - As long as `arr[j]` is strictly greater than `temp`, it slides one position to the right: `arr[j + 1] = arr[j]`.
   - Decrements `j--` to check the next element to the left.
4. **Insertion (`arr[j + 1] = temp`)**:  
   Once `arr[j] <= temp` (or `j < 0`), the correct slot is at index `j + 1`. We place `temp` right there.

---

### 3. Step-by-Step Execution Trace

Array initially: `[32, 11, 5, 65, 97, 31]`

| Iteration `i` | `temp` | Action & Shifts | Array State After Insertion |
| :---: | :---: | :--- | :--- |
| **$i = 1$** | `11` | $32 > 11 \rightarrow$ shift 32 right. Insert 11 at index 0. | `[11, 32, 5, 65, 97, 31]` |
| **$i = 2$** | `5` | $32 > 5 \rightarrow$ shift 32 right.<br>$11 > 5 \rightarrow$ shift 11 right. Insert 5 at index 0. | `[5, 11, 32, 65, 97, 31]` |
| **$i = 3$** | `65` | $32 < 65 \rightarrow$ No shift needed. Stays at index 3. | `[5, 11, 32, 65, 97, 31]` |
| **$i = 4$** | `97` | $65 < 97 \rightarrow$ No shift needed. Stays at index 4. | `[5, 11, 32, 65, 97, 31]` |
| **$i = 5$** | `31` | $97 > 31 \rightarrow$ shift 97 right.<br>$65 > 31 \rightarrow$ shift 65 right.<br>$32 > 31 \rightarrow$ shift 32 right.<br>$11 < 31 \rightarrow$ stop. Insert 31 at index 2. | `[5, 11, 31, 32, 65, 97]` |

Array is now completely sorted!

---

### 4. Complexity Analysis

- **Time Complexity:**
  - **Best Case: $O(n)$**  
    If the array is already sorted, the `while` loop condition `arr[j] > temp` fails immediately on the first comparison for every element. It makes only $n - 1$ comparisons total!
  - **Worst Case: $O(n^2)$**  
    If the array is sorted in reverse order, every single element has to be compared and shifted across all preceding elements.
  - **Average Case: $O(n^2)$**
- **Space Complexity: $O(1)$**  
  Performs all insertions in-place without needing extra array storage.

---

### 5. Why Insertion Sort is Useful
- **Extremely fast for small arrays** (often used as the base case in hybrid algorithms like Timsort or Introsort).
- **Adaptive:** Runs in $O(n)$ time on nearly-sorted data.
- **Stable Sort:** Preserves the relative order of identical elements.

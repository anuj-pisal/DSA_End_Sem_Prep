# Problem Title: Sorting an Array using Bubble Sort

## Problem Statement
Given an unsorted array of integers, sort the elements in **ascending order** using the **Bubble Sort** algorithm.

---

## Sample Examples

### Example 1
- **Input Array:** `[32, 11, 5, 65, 97, 31]`
- **Output:**
  ```text
  Before Sorting : 
  val : 	32		11		5		65		97		31		

  After Sorting : 
  val : 	5		11		31		32		65		97		
  ```
- **Explanation:**  
  The unsorted numbers are rearranged so that each element is less than or equal to the following element: $5 \le 11 \le 31 \le 32 \le 65 \le 97$.

### Example 2
- **Input Array:** `[5, 4, 3, 2, 1]`
- **Output:**
  ```text
  After Sorting : 
  val : 	1		2		3		4		5		
  ```
- **Explanation:**  
  A completely reversed array is sorted into ascending order by systematically swapping adjacent inverted pairs.

---

## Detailed Solution (In Simple English)

### 1. Intuition & The "Bubbling" Analogy
Imagine air bubbles rising to the surface of water: heavier (larger) elements slowly bubble up toward the top (end) of the array.

- In Bubble Sort, we repeatedly compare **adjacent pairs** of elements: `arr[j]` and `arr[j + 1]`.
- If the left element is larger than the right element (`arr[j] > arr[j + 1]`), they are out of order, so we **swap** them.
- After Pass 1, the largest element in the entire array is guaranteed to be pushed all the way to the last index ($n - 1$).
- After Pass 2, the second largest element is placed at index $n - 2$.
- After $n - 1$ passes, all elements are in their correct sorted positions!

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

void display(int arr[], int len) {
    cout << "val : \t";
    for(int i=0; i<len; i++) {
        cout << arr[i] << "\t\t";
    }
    cout << endl;
}

int main()
{
    int arr[] = {32,11,5,65,97,31};
    int n = sizeof(arr) / sizeof(arr[0]);

    cout << "Before Sorting : \n";
    display(arr, n);
    
    for(int i=1; i<n; i++) {
        for(int j=0; j<n-i; j++) {
            if(arr[j] > arr[j+1]) {
                int temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }

    cout << "\nAfter Sorting : \n";
    display(arr, n);

    return 0;
}
```

1. **`display()` Function**:  
   Iterates through the array from `0` to `len - 1` and prints each value separated by tabs.
2. **Outer Loop (`for(int i = 1; i < n; i++)`)**:  
   Controls the number of passes. For an array of size $n$, it runs $n - 1$ times because after placing $n - 1$ elements in their correct spots, the last remaining element is automatically in place.
3. **Inner Loop (`for(int j = 0; j < n - i; j++)`)**:  
   Iterates through adjacent elements. Notice the upper boundary `n - i`:
   - In each pass $i$, the last $i - 1$ elements are already in their final sorted positions.
   - Therefore, we do not need to compare them again!
4. **Swapping Logic**:
   - `if(arr[j] > arr[j+1])`: Checks if the pair is in the wrong order.
   - Uses a temporary variable `temp` to swap `arr[j]` and `arr[j+1]`:
     ```cpp
     int temp = arr[j];
     arr[j] = arr[j+1];
     arr[j+1] = temp;
     ```

---

### 3. Step-by-Step Walkthrough (Pass 1 Trace on `[32, 11, 5, 65, 97, 31]`)

- Compare `32` and `11`: $32 > 11 \rightarrow$ Swap: `[11, 32, 5, 65, 97, 31]`
- Compare `32` and `5`: $32 > 5 \rightarrow$ Swap: `[11, 5, 32, 65, 97, 31]`
- Compare `32` and `65`: $32 < 65 \rightarrow$ No swap: `[11, 5, 32, 65, 97, 31]`
- Compare `65` and `97`: $65 < 97 \rightarrow$ No swap: `[11, 5, 32, 65, 97, 31]`
- Compare `97` and `31`: $97 > 31 \rightarrow$ Swap: `[11, 5, 32, 65, 31, 97]`

At the end of Pass 1, the largest element (`97`) has successfully bubbled to the end!

Subsequent passes continue sorting the remaining left portion `[11, 5, 32, 65, 31]`.

---

### 4. Complexity Analysis

- **Time Complexity:**
  - **Worst Case: $O(n^2)$** (when array is in reverse order)
  - **Average Case: $O(n^2)$**
  - **Best Case: $O(n^2)$** with the basic implementation shown (can be optimized to $O(n)$ with a `swapped` boolean flag if no swaps occur in a pass).
- **Space Complexity: $O(1)$**  
  Bubble sort is an **in-place** sorting algorithm; it sorts the elements inside the original array without needing extra helper arrays.

---

### 5. Properties of Bubble Sort
- **Stable Sort:** Elements with equal values maintain their relative order.
- **In-place:** Uses only $O(1)$ additional memory.

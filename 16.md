# Problem Title: Sorting Array Elements using Merge Sort

## Problem Statement
Given an unsorted array of integers, sort the array in **ascending order** using the **Merge Sort** algorithm.

---

## Sample Examples

### Example 1
- **Input Array:** `arr = [21, 4, 6, 85, 22]`
- **Output:**
  ```text
  Sorted Array :
  4 6 21 22 85 
  ```
- **Explanation:**  
  The unsorted numbers are divided recursively into smaller halves, sorted independently, and merged back together in ascending order: $4 \le 6 \le 21 \le 22 \le 85$.

### Example 2
- **Input Array:** `arr = [38, 27, 43, 3, 9, 82, 10]`
- **Output:**
  ```text
  Sorted Array :
  3 9 10 27 38 43 82 
  ```
- **Explanation:**  
  Even with odd/even lengths and reverse ordered segments, the divide-and-conquer strategy produces a completely sorted list.

### Example 3
- **Input Array:** `arr = [5, 1]`
- **Output:**
  ```text
  Sorted Array :
  1 5 
  ```
- **Explanation:**  
  Array splits into `[5]` and `[1]`. During merge, `1 < 5`, so `1` comes first followed by `5`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach (Divide and Conquer)
Merge Sort works on the powerful principle of **Divide and Conquer**:
1. **Divide:** Split the array into two equal (or nearly equal) halves around the middle index `mid`.
2. **Conquer:** Recursively sort each half until you reach base cases (subarrays of size 1, which are already sorted).
3. **Combine (Merge):** Merge the two sorted halves back together into a single sorted array.

#### The Merging Analogy:
Imagine two decks of cards, each already sorted in your hands. You look at the top card of both decks, pick whichever card is smaller, and place it face down into a new pile. Repeat until both decks are exhausted. Merging two already-sorted lists is very easy and fast ($O(n)$ time)!

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

void merge(int arr[], int l, int mid, int h) {
    int temp[h-l+1];
    int i=l, j=mid+1, k=0;

    while(i<=mid && j <= h) {
        if(arr[i] < arr[j]) {
            temp[k++] = arr[i++];
        }
        else {
            temp[k++] = arr[j++];
        }
    }

    while(i <= mid) {
        temp[k++] = arr[i++];
    }

    while(j <= h) {
        temp[k++] = arr[j++];
    }

    for(int x=0; x<(h-l+1); x++) {
        arr[l + x] = temp[x];
    }
}

void mergeSort(int arr[], int l, int h) {
    if(l < h) {
        int mid = l + (h-l) / 2;
        mergeSort(arr, l, mid);
        mergeSort(arr, mid+1, h);
        merge(arr, l, mid, h);
    }
}

int main()
{
    int arr[] = {21,4,6,85,22};
    int n = sizeof(arr) / sizeof(arr[0]);
    int l = 0, h = n-1;

    mergeSort(arr, l, h);
    cout << "Sorted Array :\n";
    for(int i : arr) {
        cout << i << " ";
    }

    return 0;
}
```

#### Step 1: `mergeSort(int arr[], int l, int h)`
- **Base Case:** `if (l < h)` ensures recursion only continues if there are at least 2 elements in the subarray. If `l >= h`, the subarray has 0 or 1 element, which is already sorted.
- **Find Midpoint:** `mid = l + (h - l) / 2;` (prevents integer overflow compared to `(l + h) / 2`).
- **Divide:**
  - `mergeSort(arr, l, mid);` recursively sorts the left half.
  - `mergeSort(arr, mid + 1, h);` recursively sorts the right half.
- **Conquer/Merge:** `merge(arr, l, mid, h);` combines both sorted halves.

#### Step 2: `merge(int arr[], int l, int mid, int h)`
- **Temporary Buffer:** `int temp[h - l + 1];` allocates temporary storage for the combined elements.
- **Pointers:**
  - `i = l`: Traverses the left sorted subarray `[l ... mid]`.
  - `j = mid + 1`: Traverses the right sorted subarray `[mid + 1 ... h]`.
  - `k = 0`: Index for writing into `temp`.
- **First `while` Loop:** Compares `arr[i]` and `arr[j]`, putting the smaller value into `temp[k++]`.
- **Remaining Elements Loops:**
  - `while (i <= mid)` copies any leftovers from the left subarray.
  - `while (j <= h)` copies any leftovers from the right subarray.
- **Copy Back:** The `for` loop copies sorted elements from `temp` back into the original array `arr[l ... h]`.

### 3. Step-by-Step Recursion Tree Walkthrough

For `arr = [21, 4, 6, 85, 22]`:

```
                    [21, 4, 6, 85, 22]
                       /          \
                [21, 4, 6]       [85, 22]
                 /     \           /     \
             [21, 4]   [6]       [85]   [22]
             /    \     |          |      |
           [21]  [4]   [6]       [85]   [22]
             \    /     |          \     /
             [4, 21]   [6]         [22, 85]
                 \     /               |
               [4, 6, 21]          [22, 85]
                       \            /
                    [4, 6, 21, 22, 85]
```

### 4. Complexity Analysis

- **Time Complexity:**
  - **Best Case:** $O(n \log n)$
  - **Worst Case:** $O(n \log n)$
  - **Average Case:** $O(n \log n)$  
  At each level of the tree, merging all elements takes $O(n)$ time. The tree has $\log_2 n$ levels. Total work is always $O(n \log n)$ across all cases!
- **Space Complexity:** $O(n)$  
  Requires temporary array `temp` of size up to $n$ for merging, plus $O(\log n)$ call stack frames.

---

### 5. Key Highlights of Merge Sort
- **Predictable Performance:** Guaranteed $O(n \log n)$ runtime regardless of initial array ordering.
- **Stable Sort:** Preserves the relative order of duplicate elements.
- **Preferred for Linked Lists:** Can be implemented with $O(1)$ extra space on linked lists.

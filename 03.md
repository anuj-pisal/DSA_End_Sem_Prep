# Problem Title: Check if a Given Number is a Power of Two (LeetCode 231)

## Problem Statement
Given an integer $n$, check whether it is a **power of two**.

An integer $n$ is a power of two if there exists an integer $x \ge 0$ such that:
$$n = 2^x$$

For example:
- $2^0 = 1$
- $2^1 = 2$
- $2^2 = 4$
- $2^3 = 8$
- $2^4 = 16$, and so on.

---

## Sample Examples

### Example 1
- **Input:** `n = 16`
- **Output:**
  ```
  It is a power of two !
  It is a power of two !
  ```
- **Explanation:** $16 = 2^4$. Since $16$ can be expressed as $2$ raised to an integer power, it is a power of two.

### Example 2
- **Input:** `n = 6`
- **Output:**
  ```
  It is not a power of 2 !!
  It is not a power of 2 !!
  ```
- **Explanation:** $6$ can be divided by $2$ to give $3$. But $3$ cannot be divided by $2$ evenly. Thus, $6$ is not a power of two.

### Example 3
- **Input:** `n = 1`
- **Output:**
  ```
  It is a power of two !
  It is a power of two !
  ```
- **Explanation:** $2^0 = 1$. Hence, $1$ is a valid power of two.

---

## Detailed Solution (In Simple English)

The provided C++ solution demonstrates **two distinct approaches**:
1. **Recursive Approach** (`isPowerofTwo`)
2. **Bitwise Approach** (`isPowerOfTwoBitwise`)

---

### Approach 1: Recursive Division

#### Intuition:
If a number is a power of two, dividing it continuously by $2$ should eventually reduce it down to $1$ without ever leaving an odd number remainder.
- If $n == 1$, we successfully reached the base case $\rightarrow$ **True**.
- If $n$ is odd ($n \% 2 == 1$), it cannot be a power of two $\rightarrow$ **False**.
- Otherwise, repeat the check on $n / 2$.

#### Code in C++:
```cpp
bool isPowerofTwo(int n) {
    if(n==1)
        return true;
    if(n%2 == 1)
        return false;
    return isPowerofTwo(n/2);
}
```

#### Step-by-Step Walkthrough for $n = 8$:
1. `isPowerofTwo(8)`: Not 1, $8 \% 2 == 0 \rightarrow$ calls `isPowerofTwo(4)`.
2. `isPowerofTwo(4)`: Not 1, $4 \% 2 == 0 \rightarrow$ calls `isPowerofTwo(2)`.
3. `isPowerofTwo(2)`: Not 1, $2 \% 2 == 0 \rightarrow$ calls `isPowerofTwo(1)`.
4. `isPowerofTwo(1)`: Matches base case $n == 1 \rightarrow$ returns `true`!

---

### Approach 2: Bitwise Check

#### Intuition:
In binary representation, every power of two has **exactly one bit set to 1**, followed by all zeroes:
- $1 = (0001)_2$
- $2 = (0010)_2$
- $4 = (0100)_2$
- $8 = (1000)_2$
- $16 = (10000)_2$

#### The Code's Implementation:
```cpp
bool isPowerOfTwoBitwise(int n) {
    return (n & (n>>1)) == 0;
}
```
- `(n >> 1)` shifts all bits of $n$ to the right by 1 position.
- If $n$ is a power of two, its single `1` bit moves to the next position.
- Performing bitwise AND (`&`) between $n$ and `(n >> 1)` compares bits at different positions, resulting in `0`.

> [!NOTE]  
> **Important Distinction (Standard LeetCode Bitwise Trick):**  
> While `(n & (n >> 1)) == 0` is true for powers of two, some non-powers of two (like $5 = (101)_2$, where $5 \gg 1 = (010)_2$ and $101_2 \ \& \ 010_2 = 0$) also satisfy this condition.  
> The standard universal bitwise trick used in LeetCode 231 is:
> ```cpp
> bool isPowerOfTwo(int n) {
>     return n > 0 && (n & (n - 1)) == 0;
> }
> ```
> For example: $8 = (1000)_2$ and $7 = (0111)_2$. Their bitwise AND is $1000_2 \ \& \ 0111_2 = 0000_2$.

---

### 3. Complexity Analysis

| Approach | Time Complexity | Space Complexity |
| :--- | :--- | :--- |
| **Recursive Approach** | $O(\log_2 n)$ | $O(\log_2 n)$ call stack |
| **Bitwise Approach** | $O(1)$ | $O(1)$ |

- **Time Complexity:** The recursive approach divides the number by 2 at each step, taking logarithmic time $O(\log_2 n)$. The bitwise approach executes in one single CPU instruction $O(1)$.
- **Space Complexity:** Recursive calls take $O(\log_2 n)$ stack frames, while bitwise takes $O(1)$ extra space.

---

### 4. Edge Cases
- **$n \le 0$:** Zero and negative numbers are never powers of two. (A guard `if (n <= 0) return false;` should be added before division).
- **$n = 1$:** Properly returns `true` because $2^0 = 1$.

# Problem Title: Intersection of Two Arrays (LeetCode 349)

## Problem Statement
Given two integer arrays `arr1` and `arr2`, return an array of their **intersection**. Each element in the result must be **unique** (no duplicates), and the elements may appear in any order.

An element belongs to the intersection if and only if it appears in **both** arrays.

---

## Sample Examples

### Example 1
- **Input:** 
  - `arr1 = [2, 4, 1, 5, 2]`
  - `arr2 = [2, 1, 3, 9, 2]`
- **Output:** `Intersected values : 1 2 ` (or `2 1`)
- **Explanation:**  
  The numbers common to both arrays are `1` and `2`. Even though `2` appears multiple times in both arrays, it appears only once in the unique intersection output.

### Example 2
- **Input:** 
  - `arr1 = [4, 9, 5]`
  - `arr2 = [9, 4, 9, 8, 4]`
- **Output:** `Intersected values : 4 9 `
- **Explanation:**  
  Only `4` and `9` are present in both arrays.

### Example 3
- **Input:** 
  - `arr1 = [1, 2, 3]`
  - `arr2 = [4, 5, 6]`
- **Output:** `Intersected values : ` *(empty)*
- **Explanation:**  
  There are no common elements between the two arrays.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
To find the intersection without using slow $O(n \times m)$ nested loops:
- We use a **Hash Map (`unordered_map<int, int>`)** to track presence across both arrays in $O(1)$ average time per operation.
- **Phase 1 (Register `arr1`):**  
  For every element in `arr1`, store it in the hash map with a baseline count of `1`. (Using `if (map.count(i) == 0)` ensures duplicate entries in `arr1` do not inflate the count beyond 1).
- **Phase 2 (Scan `arr2`):**  
  For every element in `arr2`, increment `map[i] = map[i] + 1`.
  - If the element was already in `arr1`, its count was `1`, so it now becomes $\ge 2$.
  - If the element was NOT in `arr1`, C++ default-initializes it to `0`, so adding `1` makes it `1`.
- **Phase 3 (Collect Common Elements):**  
  Traverse the map. Any key with a value `pair.second > 1` must have appeared in both arrays!

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
#include<unordered_map>

using namespace std;

int main()
{
    int arr1[] = {2,4,1,5,2};
    int arr2[] = {2,1,3,9,2};
    unordered_map<int, int> map;

    for(int i : arr1) {
        if(map.count(i) == 0) {
            map[i] = 1;
        }
    }

    for(int i : arr2) {
        map[i] = map[i] + 1;
    }

    cout << "Intersected values : ";
    for(auto pair : map) {
        if(pair.second > 1) {
            cout << pair.first << " ";
        }
    }
    
    return 0;
}
```

1. **Map Construction from `arr1`**:
   - `for(int i : arr1)`: Loops over each value in `arr1`.
   - `if(map.count(i) == 0) map[i] = 1;`: Sets the value to 1 for distinct numbers. For `arr1 = [2, 4, 1, 5, 2]`, the map stores `{2: 1, 4: 1, 1: 1, 5: 1}`.
2. **Increment from `arr2`**:
   - `for(int i : arr2)`: Loops over `arr2 = [2, 1, 3, 9, 2]`.
   - `map[i] = map[i] + 1;`:
     - `2` was 1 $\rightarrow$ becomes 2, then 3.
     - `1` was 1 $\rightarrow$ becomes 2.
     - `3` was not in map $\rightarrow$ becomes 1.
     - `9` was not in map $\rightarrow$ becomes 1.
3. **Filtering Intersection**:
   - `for(auto pair : map)`: Inspects each entry.
   - `if(pair.second > 1)`: Prints the key (`pair.first`) because it was present in both sets.

---

### 3. Step-by-Step Dry Run

Initial Arrays: `arr1 = [2, 4, 1, 5, 2]`, `arr2 = [2, 1, 3, 9, 2]`

- **After Pass 1 on `arr1`:**  
  `map = { 2: 1, 4: 1, 1: 1, 5: 1 }`

- **Pass 2 on `arr2`:**
  - See `2`: `map[2]` becomes $1 + 1 = 2$
  - See `1`: `map[1]` becomes $1 + 1 = 2$
  - See `3`: `map[3]` becomes $0 + 1 = 1$
  - See `9`: `map[9]` becomes $0 + 1 = 1$
  - See `2`: `map[2]` becomes $2 + 1 = 3$

- **Pass 3 (Condition `value > 1`):**
  - Key `2`: value $3 > 1$ $\rightarrow$ **Print `2`**
  - Key `4`: value $1 \ngtr 1$ $\rightarrow$ Skip
  - Key `1`: value $2 > 1$ $\rightarrow$ **Print `1`**
  - Key `5`: value $1 \ngtr 1$ $\rightarrow$ Skip
  - Key `3`: value $1 \ngtr 1$ $\rightarrow$ Skip
  - Key `9`: value $1 \ngtr 1$ $\rightarrow$ Skip

Output: `Intersected values : 1 2 `

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n + m)$  
  - Pass 1 takes $O(n)$ where $n = \text{size of } arr1$.
  - Pass 2 takes $O(m)$ where $m = \text{size of } arr2$.
  - Pass 3 traverses the map of at most $n + m$ keys.
  - Overall time is linear $O(n + m)$.
- **Space Complexity:** $O(n + m)$  
  The hash map stores unique keys from both arrays.

---

### 5. Alternative Approach: Using `std::unordered_set`
A classic LeetCode 349 solution also uses two sets:
```cpp
unordered_set<int> set1(arr1, arr1 + n1);
unordered_set<int> resultSet;
for (int x : arr2) {
    if (set1.count(x)) resultSet.insert(x);
}
```
Both approaches achieve optimal $O(n + m)$ time.

# Problem Title: Find Second Largest and Second Smallest Element from an Array

## Problem Statement
Given an array of integers of size $n$ ($n \ge 2$), find and display:
1. The **second largest** distinct element in the array.
2. The **second smallest** distinct element in the array.

The solution should find both in a single pass without sorting the array.

---

## Sample Examples

### Example 1
- **Input Array:** `arr = [21, 44, 7, 2, 24, 78, 56]`
- **Output:**
  ```text
  Second Largest : 56
  Second Smallest : 7
  ```
- **Explanation:**  
  - Elements in ascending order: `2, 7, 21, 24, 44, 56, 78`
  - The largest element is `78`, so the **second largest** is `56`.
  - The smallest element is `2`, so the **second smallest** is `7`.

### Example 2
- **Input Array:** `arr = [10, 5, 20, 8]`
- **Output:**
  ```text
  Second Largest : 10
  Second Smallest : 8
  ```
- **Explanation:**  
  - Largest: `20` $\rightarrow$ Second Largest: `10`
  - Smallest: `5` $\rightarrow$ Second Smallest: `8`

### Example 3
- **Input Array:** `arr = [1, 2, 3, 4, 5]`
- **Output:**
  ```text
  Second Largest : 4
  Second Smallest : 2
  ```
- **Explanation:**  
  - Second largest is `4`.
  - Second smallest is `2`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
A naive way to solve this is to sort the array first in ascending order, which takes $O(n \log n)$ time.

However, we can do much better: we can find both in **a single linear scan ($O(n)$ time)** using tracking variables:

#### Finding Second Largest:
- Keep two variables: `largest` and `sec_largest`.
- Initialize them using the first two elements:
  - `largest = max(arr[0], arr[1])`
  - `sec_largest = min(arr[0], arr[1])`
- Iterate through the rest of the array (from index 2 to $n - 1$):
  - **Case 1:** If current element `arr[i] > largest`:
    - The old `largest` is dethroned and becomes the new `sec_largest`!
    - `arr[i]` becomes the new `largest`.
  - **Case 2:** If `arr[i]` is not greater than `largest`, but is greater than `sec_largest` (and not a duplicate of `largest`):
    - `arr[i]` updates `sec_largest`.

#### Finding Second Smallest:
- Symmetric logic:
  - `smallest = min(arr[0], arr[1])`
  - `sec_smallest = max(arr[0], arr[1])`
- For each subsequent element:
  - **Case 1:** If `arr[i] < smallest`:
    - The old `smallest` becomes the new `sec_smallest`.
    - `arr[i]` becomes the new `smallest`.
  - **Case 2:** If `arr[i]` is between `smallest` and `sec_smallest`:
    - `arr[i]` updates `sec_smallest`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

void secLargest(int arr[], int n) {
    int largest = max(arr[0], arr[1]);
    int sec_largest = min(arr[0], arr[1]);

    for(int i=2; i<n; i++) {
        if(arr[i] > largest) {
            sec_largest = largest;
            largest = arr[i];
        }
        else if(arr[i] > sec_largest && arr[i] != largest) {
            sec_largest = arr[i];
        }
    }

    cout << "Second Largest : " << sec_largest;
}

void secSmallest(int arr[], int n) {
    int smallest = min(arr[0], arr[1]);
    int sec_smallest = max(arr[0], arr[1]);

    for(int i=2; i<n; i++) {
        if(arr[i] < smallest) {
            sec_smallest = smallest;
            smallest = arr[i];
        }
        else if(arr[i] < sec_smallest && arr[i] != smallest) {
            sec_smallest = arr[i];
        }
    }

    cout << "Second Smallest : " << sec_smallest;
}

int main()
{
    int arr[] = {21,44,7,2,24,78,56};
    int n = sizeof(arr) / sizeof(arr[0]);

    secLargest(arr, n);
    cout << endl;
    secSmallest(arr, n);

    return 0;
}
```

> [!TIP]  
> In `secSmallest()`, ensure the output label prints `"Second Smallest : "` instead of `"Second Largest : "`.

### 3. Step-by-Step Execution Walkthrough

Input: `arr = [21, 44, 7, 2, 24, 78, 56]`

#### Trace for `secLargest`:
- Initial: `largest = max(21, 44) = 44`, `sec_largest = min(21, 44) = 21`

| Index `i` | Element `arr[i]` | Condition Checked | `largest` | `sec_largest` |
| :---: | :---: | :--- | :---: | :---: |
| `i = 2` | 7 | $7 > 44$ (F), $7 > 21$ (F) | 44 | 21 |
| `i = 3` | 2 | $2 > 44$ (F), $2 > 21$ (F) | 44 | 21 |
| `i = 4` | 24 | $24 > 44$ (F), $24 > 21$ (T) | 44 | **24** |
| `i = 5` | 78 | $78 > 44$ (**T**) $\rightarrow$ `sec_largest = 44` | **78** | **44** |
| `i = 6` | 56 | $56 > 78$ (F), $56 > 44$ (T) | 78 | **56** |

**Result:** `Second Largest = 56`.

---

#### Trace for `secSmallest`:
- Initial: `smallest = min(21, 44) = 21`, `sec_smallest = max(21, 44) = 44`

| Index `i` | Element `arr[i]` | Condition Checked | `smallest` | `sec_smallest` |
| :---: | :---: | :--- | :---: | :---: |
| `i = 2` | 7 | $7 < 21$ (**T**) $\rightarrow$ `sec_smallest = 21` | **7** | **21** |
| `i = 3` | 2 | $2 < 7$ (**T**) $\rightarrow$ `sec_smallest = 7` | **2** | **7** |
| `i = 4` | 24 | $24 < 2$ (F), $24 < 7$ (F) | 2 | 7 |
| `i = 5` | 78 | $78 < 2$ (F), $78 < 7$ (F) | 2 | 7 |
| `i = 6` | 56 | $56 < 2$ (F), $56 < 7$ (F) | 2 | 7 |

**Result:** `Second Smallest = 7`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  Both `secLargest` and `secSmallest` iterate through the array once from index 2 to $n - 1$. No sorting or nested loops are used.
- **Space Complexity:** $O(1)$  
  Only four scalar variables are used (`largest`, `sec_largest`, `smallest`, `sec_smallest`), requiring minimal constant extra memory.

---

### 5. Edge Cases
- **Duplicates of the largest/smallest:** The condition `arr[i] != largest` ensures that if the largest element appears multiple times, it is not mistakenly taken as the second largest.
- **Array Size < 2:** Requires at least 2 distinct elements to have a valid second largest/smallest.

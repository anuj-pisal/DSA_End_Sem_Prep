# Problem Title: Factorial of a Given Number

## Problem Statement
Given a non-negative integer $n$, calculate its **factorial**, denoted as $n!$.

The factorial of a non-negative integer $n$ is the product of all positive integers less than or equal to $n$:
$$n! = n \times (n - 1) \times (n - 2) \times \dots \times 2 \times 1$$

Special cases:
- $0! = 1$
- $1! = 1$

---

## Sample Examples

### Example 1
- **Input:** `n = 5`
- **Output:** `Factorial of 5 is : 120`
- **Explanation:**  
  $$5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$$

### Example 2
- **Input:** `n = 0`
- **Output:** `Factorial of 0 is : 1`
- **Explanation:**  
  By mathematical definition, the factorial of 0 is always 1 ($0! = 1$).

### Example 3
- **Input:** `n = 3`
- **Output:** `Factorial of 3 is : 6`
- **Explanation:**  
  $$3! = 3 \times 2 \times 1 = 6$$

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
To find the factorial of a number $n$, we can break it down into a smaller sub-problem:
$$\text{factorial}(n) = n \times \text{factorial}(n - 1)$$

Because the problem can be defined in terms of itself with a smaller input, this is a classic candidate for **Recursion**.
- A **recursive function** is a function that calls itself.
- Every recursive function needs a **base condition** to stop the recursion so it does not continue forever (which would cause a stack overflow).
- For factorial:
  - When $n = 0$ or $n = 1$, we know the answer immediately: it is `1`. This is our **base condition**.
  - For any $n > 1$, we multiply $n$ by the factorial of $(n - 1)$.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int factorial(int n) {
    if(n==0 || n==1) 
        return 1;
    return n * factorial(n-1);
}

int main() {
    int n;
    cout << "Enter n : ";
    cin >> n;
    int res = factorial(n);
    cout << "Factorial of " << n << " is : " << res << endl;
    return 0;
}
```

1. **`int factorial(int n)` Function**:
   - `if (n == 0 || n == 1) return 1;`
     - This is the **base condition**. If $n$ is either 0 or 1, the function returns 1 without making any further recursive calls.
   - `return n * factorial(n - 1);`
     - If $n > 1$, the function pauses, calls `factorial(n - 1)`, waits for that result, multiplies it by $n$, and returns the total.

2. **`main()` Function**:
   - Prompts the user to enter a number `n`.
   - Reads `n` using `cin >> n`.
   - Calls `factorial(n)` and stores the answer in variable `res`.
   - Prints the result to the console.

---

### 3. Step-by-Step Execution Walkthrough (Dry Run for $n = 4$)

Let's trace how the computer executes `factorial(4)`:

1. `factorial(4)` calls `4 * factorial(3)`
2. `factorial(3)` calls `3 * factorial(2)`
3. `factorial(2)` calls `2 * factorial(1)`
4. `factorial(1)` hits the base case (`n == 1`) and returns `1`.

Now the calls resolve backwards (unwinding the call stack):
- `factorial(2)` receives `1` $\rightarrow$ returns `2 * 1 = 2`
- `factorial(3)` receives `2` $\rightarrow$ returns `3 * 2 = 6`
- `factorial(4)` receives `6` $\rightarrow$ returns `4 * 6 = 24`

Final Result: **24**.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  The function calls itself $n$ times (from $n$ down to 1), doing constant time work $O(1)$ at each step.
- **Space Complexity:** $O(n)$  
  Each recursive call is placed on the system's **call stack**. Since there are $n$ nested calls waiting to return, it consumes $O(n)$ memory on the call stack.

---

### 5. Edge Cases & Notes
- **$n = 0$:** Handled properly by the base case (`return 1`).
- **Integer Overflow:** Standard 32-bit `int` in C++ can only hold values up to $\approx 2 \times 10^9$. Factorials grow extremely fast ($13! = 6,227,020,800$, which exceeds standard 32-bit `int`). For larger $n$, consider using `long long` or large integer data structures.

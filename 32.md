# Problem Title: Searching an Element in a 2D Matrix (Linear Search)

## Problem Statement
Given a 2D matrix `mat` of size $\text{rows} \times \text{cols}$ and an integer `target`, determine whether the `target` value exists anywhere inside the matrix.

- If the target is found, display `"Target is in matrix !!"`.
- If the target is not present, display `"Target is not there in matrix !"`.

---

## Sample Examples

### Example 1
- **Input Matrix:**
  ```text
  [
    [2,  5,  1],
    [4,  1, 13],
    [3, 67,  9]
  ]
  ```
- **Target:** `3`
- **Output:** `Target is in matrix !!`
- **Explanation:**  
  The target `3` is located at row index 2, column index 0 (`mat[2][0] == 3`).

### Example 2
- **Input Matrix:**
  ```text
  [
    [2,  5,  1],
    [4,  1, 13],
    [3, 67,  9]
  ]
  ```
- **Target:** `99`
- **Output:** `Target is not there in matrix !`
- **Explanation:**  
  Every cell in the matrix is examined, but none match `99`.

### Example 3
- **Input Matrix:**
  ```text
  [
    [2, 5],
    [4, 1]
  ]
  ```
- **Target:** `2`
- **Output:** `Target is in matrix !!`
- **Explanation:**  
  Found immediately at the very first element `mat[0][0]`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
When a 2D matrix is unsorted:
- You must inspect each row from top to bottom, and within each row, inspect each column from left to right.
- This is the 2D equivalent of **Linear Search**:
  1. Outer loop `i` scans each row from `0` to $\text{rows} - 1$.
  2. Inner loop `j` scans each column from `0` to $\text{cols} - 1$.
  3. If `mat[i][j] == target`, report success and exit immediately.
  4. If both loops finish without finding the target, report that the element is absent.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int mat[][3] = {{2,5,1}, {4,1,13}, {3,67,9}};
    int rows = 3, cols = 3;
    int target = 3;
    
    for(int i=0; i<rows; i++) {
        for(int j=0; j<cols; j++) {
            if(mat[i][j] == target) {
                cout << "Target is in matrix !!" << endl;
                return 2;
            }
        }
    }

    cout << "Target is not there in matrix !" << endl;

    return 0;
}
```

1. **Matrix Definition**:
   - 3 rows, 3 columns:
     - Row 0: `[2, 5, 1]`
     - Row 1: `[4, 1, 13]`
     - Row 2: `[3, 67, 9]`
   - `target = 3`.
2. **Nested Search Loops**:
   - `i = 0`: Checks `mat[0][0] = 2`, `mat[0][1] = 5`, `mat[0][2] = 1`. None match.
   - `i = 1`: Checks `mat[1][0] = 4`, `mat[1][1] = 1`, `mat[1][2] = 13`. None match.
   - `i = 2`: Checks `mat[2][0] = 3`.
     - `mat[2][0] == 3` matches target!
     - Prints `"Target is in matrix !!"`.
     - `return 2;` terminates the program immediately.
3. **Absence Fall-through**:
   - If no cell matches `target`, the loops terminate and line 19 prints `"Target is not there in matrix !"`.

---

### 3. Step-by-Step Dry Run (Target = 3)

| Cell Checked (`mat[i][j]`) | Value | Match with Target (3)? | Action |
| :---: | :---: | :---: | :--- |
| `mat[0][0]` | 2 | False | Continue |
| `mat[0][1]` | 5 | False | Continue |
| `mat[0][2]` | 1 | False | Continue |
| `mat[1][0]` | 4 | False | Continue |
| `mat[1][1]` | 1 | False | Continue |
| `mat[1][2]` | 13 | False | Continue |
| `mat[2][0]` | 3 | **True** | **Target Found!** Exit. |

---

### 4. Complexity Analysis

- **Time Complexity:**
  - **Best Case: $O(1)$**  
    Target is located at `mat[0][0]`.
  - **Worst Case: $O(\text{rows} \times \text{cols})$**  
    Target is at the very last cell `mat[rows - 1][cols - 1]` or does not exist in the matrix.
  - **Average Case: $O(\text{rows} \times \text{cols})$**
- **Space Complexity: $O(1)$**  
  No extra memory is allocated.

---

### 5. When to Use Linear Search vs Binary Search in 2D
- **Unsorted Matrix (like this problem):** Linear search is mandatory because elements are in random order.
- **Row-wise and Column-wise Sorted Matrix (LeetCode 74 / 240):** Binary search or staircase search can find the element in $O(\log(R \times C))$ or $O(R + C)$ time!

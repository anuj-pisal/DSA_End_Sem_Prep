# Problem Title: Row with Maximum Ones (LeetCode 2643)

## Problem Statement
Given an $m \times n$ binary matrix `mat` (where each element is either `0` or `1`), find the 0-indexed row that contains the **maximum count of ones**, and the number of ones in that row.

If there is a tie between multiple rows, the row with the **smallest row index** should be chosen.

Output the result in the format `[row_index, count_of_ones]`.

---

## Sample Examples

### Example 1
- **Input Matrix:**
  ```text
  [
    [0, 0, 0],
    [1, 0, 1],
    [1, 1, 1]
  ]
  ```
- **Output:** `[2, 3]`
- **Explanation:**  
  - Row 0 has $0 + 0 + 0 = 0$ ones.
  - Row 1 has $1 + 0 + 1 = 2$ ones.
  - Row 2 has $1 + 1 + 1 = 3$ ones.  
  The maximum number of ones is 3, occurring at row 2.

### Example 2
- **Input Matrix:**
  ```text
  [
    [0, 1],
    [1, 0]
  ]
  ```
- **Output:** `[0, 1]`
- **Explanation:**  
  Both Row 0 and Row 1 have exactly one `1`. Because ties are broken in favor of the smaller index, row 0 is returned.

### Example 3
- **Input Matrix:**
  ```text
  [
    [0, 0],
    [0, 0]
  ]
  ```
- **Output:** `[0, 0]`
- **Explanation:**  
  All rows have zero ones. Row 0 is chosen by index tie-breaking.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
Because the matrix entries are only `0` or `1`:
- The number of ones in any row is simply the **sum** of all elements in that row!
- We can inspect the matrix row by row:
  1. Start with Row 0: Sum its elements to establish the initial `count` and set `maxRow = 0`.
  2. For every remaining row (from Row 1 to Row $m - 1$):
     - Calculate the row's total ones `curr`.
     - If `curr > count` (strictly greater), this row beats the previous best! We update `count = curr` and `maxRow = i`.
     - If `curr <= count`, we keep our existing `maxRow` (preserving the smaller index on ties).
  3. Print `[maxRow, count]`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int mat[][3] = {{0,0,0}, {1,0,1}, {1,1,1}};
    int rows = sizeof(mat) / sizeof(mat[0]);
    int cols = sizeof(mat[0]) / sizeof(mat[0][0]);

    int maxRow = 0, count = 0;
    for(int j=0; j<cols; j++) {
        count += mat[0][j];
    }   

    for(int i=1; i<rows; i++) {
        int curr = 0;
        for(int j=0; j<cols; j++) {
            curr += mat[i][j];
        }
        if(curr > count) {
            count = curr;
            maxRow = i;
        }
    }

    cout << "[" << maxRow << ", " << count << "]";
    
    return 0;
}
```

1. **Matrix Dimensions**:
   - `rows = sizeof(mat) / sizeof(mat[0]);` gives $3$.
   - `cols = sizeof(mat[0]) / sizeof(mat[0][0]);` gives $3$.
2. **Row 0 Initialization**:
   - Sums elements of row 0: `mat[0][0] + mat[0][1] + mat[0][2] = 0 + 0 + 0 = 0`.
   - Sets baseline `count = 0`, `maxRow = 0`.
3. **Outer Row Loop (`for (int i = 1; i < rows; i++)`)**:
   - For `i = 1`: Sums `1 + 0 + 1 = 2`. Since $2 > 0$, updates `count = 2`, `maxRow = 1`.
   - For `i = 2`: Sums `1 + 1 + 1 = 3`. Since $3 > 2$, updates `count = 3`, `maxRow = 2`.
4. **Display**:
   - Outputs `[2, 3]`.

---

### 3. Step-by-Step Dry Run

Matrix:
- Row 0: `[0, 0, 0]`
- Row 1: `[1, 0, 1]`
- Row 2: `[1, 1, 1]`

| Row `i` | Elements | Row Sum (`curr`) | Comparison (`curr > count`) | `maxRow` | `count` |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **0** | `0, 0, 0` | 0 | Baseline | 0 | 0 |
| **1** | `1, 0, 1` | 2 | $2 > 0$ (**True**) | **1** | **2** |
| **2** | `1, 1, 1` | 3 | $3 > 2$ (**True**) | **2** | **3** |

Final Output: `[2, 3]`

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\text{rows} \times \text{cols})$  
  Every cell in the matrix is visited exactly once.
- **Space Complexity:** $O(1)$  
  Uses only constant scalar variables (`maxRow`, `count`, `curr`, `rows`, `cols`).

---

### 5. Tie-Breaking Property
Using strict inequality `if (curr > count)` ensures that when a later row has the exact same count as an earlier row, the earlier (smaller) row index is preserved, satisfying the tie-break requirement without any extra logic.

# Problem Title: Sorting an Array using Selection Sort

## Problem Statement
Given an unsorted array of integers, sort the elements in **ascending order** using the **Selection Sort** algorithm.

---

## Sample Examples

### Example 1
- **Input Array:** `[32, 11, 5, 65, 97, 31]`
- **Output:**
  ```text
  Before Sorting : 
  val : 	32		11		5		65		97		31		

  After Sorting : 
  val : 	5		11		31		32		65		97		
  ```
- **Explanation:**  
  In each pass, the smallest element in the remaining unsorted section is identified and swapped into the current front position.

### Example 2
- **Input Array:** `[64, 25, 12, 22, 11]`
- **Output:**
  ```text
  After Sorting : 
  val : 	11		12		22		25		64		
  ```
- **Explanation:**  
  Pass 1 finds `11` and puts it at index 0. Pass 2 finds `12` and puts it at index 1. Pass 3 finds `22` and puts it at index 2, and so on.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
The name **Selection Sort** comes from its primary action: **select** the smallest element.

- We divide the array conceptually into two regions:
  - **Sorted portion:** on the left.
  - **Unsorted portion:** on the right.
- In each round:
  1. Scan through the entire unsorted region to find the index of the **minimum element**.
  2. Swap that minimum element with the first element of the unsorted region.
  3. Expand the sorted region by one position and repeat until the whole array is sorted.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

void display(int arr[], int len) {
    cout << "val : \t";
    for(int i=0; i<len; i++) {
        cout << arr[i] << "\t\t";
    }
    cout << endl;
}

int main()
{
    int arr[] = {32,11,5,65,97,31};
    int n = sizeof(arr) / sizeof(arr[0]);

    cout << "Before Sorting : \n";
    display(arr, n);
    
    for(int i=0; i<n; i++) {
        int min = i;
        for(int j=i+1; j<n; j++) {
            if(arr[j] < arr[min]) {
                min = j;
            }
        }
        if(min != i) {
            int temp = arr[min];
            arr[min] = arr[i];
            arr[i] = temp;
        }
    }

    cout << "\nAfter Sorting : \n";
    display(arr, n);

    return 0;
}
```

1. **Outer Loop (`for(int i = 0; i < n; i++)`)**:  
   Points to the beginning of the unsorted subarray. Index `i` is the slot where the smallest remaining value will be placed.
2. **Finding the Minimum (`int min = i;`)**:  
   We assume the element at `i` is currently the smallest.
3. **Inner Loop (`for(int j = i + 1; j < n; j++)`)**:  
   Scans the rest of the array. Whenever it encounters an element smaller than `arr[min]` (`if(arr[j] < arr[min])`), it updates `min = j`.
4. **Conditional Swap**:  
   `if (min != i)`: If a smaller value was found elsewhere (`min` changed), we swap `arr[min]` and `arr[i]` using `temp`. If `min == i`, the element was already in its correct spot, so no unnecessary swap is performed!

### 4. Complexity Analysis

- **Time Complexity:**
  - **Best Case:** $O(n^2)$
  - **Worst Case:** $O(n^2)$
  - **Average Case:** $O(n^2)$  
  Notice that regardless of how sorted the input array already is, Selection Sort must always scan through the rest of the array to confirm the minimum element. Total comparisons = $(n-1) + (n-2) + \dots + 1 = \frac{n(n-1)}{2} = O(n^2)$.
- **Space Complexity:** $O(1)$  
  Operates directly on the array in-place.
- **Key Advantage:**  
  Makes at most **$O(n)$ swaps** (at most 1 swap per outer loop iteration), which is minimal compared to Bubble Sort's $O(n^2)$ swaps.

### 5. Summary Comparison

| Sorting Algorithm | Best Time | Worst Time | Space | Swaps |
| :--- | :---: | :---: | :---: | :---: |
| **Bubble Sort** | $O(n)$ (optimized) | $O(n^2)$ | $O(1)$ | Up to $O(n^2)$ |
| **Insertion Sort** | $O(n)$ | $O(n^2)$ | $O(1)$ | Up to $O(n^2)$ shifts |
| **Selection Sort** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | At most $O(n)$ swaps |

# Problem Title: Check if a Given Number is a Power of Four (LeetCode 342)

## Problem Statement
Given an integer $n$, determine whether it is a **power of four**.

An integer $n$ is a power of four if there exists an integer $x \ge 0$ such that:
$$n = 4^x$$

For example:
- $4^0 = 1$
- $4^1 = 4$
- $4^2 = 16$
- $4^3 = 64$
- $4^4 = 256$, and so on.

---

## Sample Examples

### Example 1
- **Input:** `n = 16`
- **Output:** `It is a power of 4 !!`
- **Explanation:** $16 = 4^2$. Since $16$ is $4$ raised to the power $2$, it is a valid power of 4.

### Example 2
- **Input:** `n = 5`
- **Output:** `It is not a power of 4 !`
- **Explanation:** $5$ cannot be divided evenly by $4$ ($5 \% 4 = 1 \ne 0$). Hence, it cannot be a power of four.

### Example 3
- **Input:** `n = 8`
- **Output:** `It is not a power of 4 !`
- **Explanation:** Although $8$ is a power of two ($2^3$), it cannot be represented as $4^x$ for any integer $x$ ($4^1 = 4$, $4^2 = 16$). Dividing $8$ by $4$ leaves $2$, which is not divisible by $4$.

### Example 4
- **Input:** `n = 1`
- **Output:** `It is a power of 4 !!`
- **Explanation:** $4^0 = 1$. The number 1 is always a power of 4.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
Any power of four has the following mathematical property:
- If we continuously divide $n$ by $4$, it must eventually reduce all the way down to $1$ without ever leaving a non-zero remainder.
- If at any step $n$ is not divisible by $4$ (i.e. $n \% 4 \ne 0$), we can immediately say it is **not** a power of four.

This leads naturally to a recursive solution:
1. **Base Case 1:** If $n == 1$, return `true`.
2. **Base Case 2:** If $n \% 4 \ne 0$ (not evenly divisible by 4), return `false`.
3. **Recursive Step:** Otherwise, divide $n$ by $4$ and repeat the test: `return isPowerOf4(n / 4);`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int isPowerOf4(int n) {
    if(n==1)
        return true;
    if(n%4 != 0) 
        return false;
    return isPowerOf4(n/4);
}

int main()
{
    int n ;
    cout << "Enter a number : " << endl;
    cin >> n;

    isPowerOf4(n) ?
        cout << "It is a power of 4 !!" :
        cout << "It is not a power of 4 !";

    return 0;
}
```

1. **`int isPowerOf4(int n)` Function**:
   - `if (n == 1) return true;`  
     This is the successful terminal condition. Any number that was repeatedly divided by 4 and reached 1 is confirmed to be a power of four.
   - `if (n % 4 != 0) return false;`  
     If $n$ cannot be divided cleanly by 4, it is immediately rejected.
   - `return isPowerOf4(n / 4);`  
     Divides the number by 4 and passes it to the next recursive invocation.
2. **`main()` Function**:
   - Prompts for input and reads integer `n`.
   - Uses the ternary conditional operator `condition ? true_expression : false_expression` to print the output message directly.

---

### 3. Step-by-Step Execution Walkthrough

#### Case A: $n = 64$
1. `isPowerOf4(64)`: $64 \ne 1$, $64 \% 4 == 0 \rightarrow$ calls `isPowerOf4(16)`.
2. `isPowerOf4(16)`: $16 \ne 1$, $16 \% 4 == 0 \rightarrow$ calls `isPowerOf4(4)`.
3. `isPowerOf4(4)`: $4 \ne 1$, $4 \% 4 == 0 \rightarrow$ calls `isPowerOf4(1)`.
4. `isPowerOf4(1)`: Matches base case $n == 1 \rightarrow$ returns `true` (1).
- Result: **"It is a power of 4 !!"**

#### Case B: $n = 8$
1. `isPowerOf4(8)`: $8 \ne 1$, $8 \% 4 == 0 \rightarrow$ calls `isPowerOf4(2)`.
2. `isPowerOf4(2)`: $2 \ne 1$, $2 \% 4 = 2 \ne 0 \rightarrow$ returns `false` (0).
- Result: **"It is not a power of 4 !"**

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\log_4 n)$  
  In each recursive step, the number $n$ is divided by 4. The number of recursive calls is proportional to $\log_4 n$, which executes very quickly (e.g., at most 16 iterations for a 32-bit integer).
- **Space Complexity:** $O(\log_4 n)$  
  Memory used on the call stack for the recursive function frames.

---

### 5. Edge Cases & Notes
- **$n \le 0$:** If $n = 0$ or negative, $0 \% 4 == 0$ which leads to infinite recursion or incorrect behavior unless guarded. Adding `if (n <= 0) return false;` at the beginning makes it completely robust.
- **$n = 1$:** Correctly returns `true` since $4^0 = 1$.

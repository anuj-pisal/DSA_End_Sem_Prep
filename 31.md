# Problem Title: Return Column Index with Maximum Even Numbers in a 2D Matrix

## Problem Statement
Given a 2D matrix `mat` of integers with `rows` rows and `cols` columns, find the **0-indexed column** that contains the **maximum count of even numbers**, and the count of even numbers in that column.

Output the result in the format `[maxCol, maxEven]`.

---

## Sample Examples

### Example 1
- **Input Matrix:**
  ```text
  [
    [34,  1,  4],
    [ 3,  4,  2],
    [ 3, 66,  4],
    [23, 44, 32]
  ]
  ```
- **Output:** `[2, 4]`
- **Explanation:**  
  Checking even numbers in each column:
  - Column 0: `34, 3, 3, 23` $\rightarrow$ only `34` is even (Count = 1).
  - Column 1: `1, 4, 66, 44` $\rightarrow$ `4, 66, 44` are even (Count = 3).
  - Column 2: `4, 2, 4, 32` $\rightarrow$ all 4 numbers are even (Count = 4).  
  Column 2 has the highest count of even numbers ($4$).

### Example 2
- **Input Matrix:**
  ```text
  [
    [1, 3],
    [5, 7]
  ]
  ```
- **Output:** `[0, 0]`
- **Explanation:**  
  There are no even numbers in any column. Column 0 is returned by default with count 0.

### Example 3
- **Input Matrix:**
  ```text
  [
    [2, 4],
    [6, 8]
  ]
  ```
- **Output:** `[0, 2]`
- **Explanation:**  
  Both Column 0 and Column 1 have two even numbers. On ties, the earlier column index (0) is kept.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
- An integer `x` is **even** if it is cleanly divisible by 2: `x % 2 == 0`.
- To find which vertical column has the most even numbers:
  1. Traverse each column from left to right.
  2. For a specific column `j`, walk through all its rows from top to bottom.
  3. Keep a counter of how many elements satisfy `mat[i][j] % 2 == 0`.
  4. Compare with the current maximum even count:
     - If the current column has strictly more even numbers than `maxEven`, update `maxEven = curr` and `maxCol = j`.
  5. Print `[maxCol, maxEven]`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int mat[][3] = {{34,1,4}, {3,4,2}, {3,66,4}, {23,44,32}};
    int cols = 3, rows = 4; 
    int maxCol = 0;
    int maxEven = 0;

    for(int i=0; i<rows; i++) {
        maxEven = maxEven + (mat[i][0] % 2 == 0 ? 1 : 0);
    }
    
    for(int j=1; j<cols; j++) {
        int curr = 0;
        for(int i=0; i<rows; i++) {
            curr = curr + (mat[i][j] % 2 == 0 ? 1 : 0);
        }
        if(curr > maxEven) {
            maxEven = curr;
            maxCol = j;
        }
    }

    cout << "[" << maxCol << ", " << maxEven << "]";

    return 0;
}
```

1. **Column 0 Baseline**:
   - `for(int i=0; i<rows; i++)`: Checks Column 0:
     - `mat[0][0] = 34` (even $\rightarrow +1$)
     - `mat[1][0] = 3` (odd $\rightarrow +0$)
     - `mat[2][0] = 3` (odd $\rightarrow +0$)
     - `mat[3][0] = 23` (odd $\rightarrow +0$)
   - `maxEven = 1`, `maxCol = 0`.
2. **Outer Loop for Remaining Columns (`j = 1` to `cols - 1`)**:
   - **Column 1 (`j = 1`)**:
     - `mat[0][1] = 1` (odd)
     - `mat[1][1] = 4` (even $\rightarrow +1$)
     - `mat[2][1] = 66` (even $\rightarrow +1$)
     - `mat[3][1] = 44` (even $\rightarrow +1$)
     - Total `curr = 3`. Since $3 > 1$, update `maxEven = 3, maxCol = 1`.
   - **Column 2 (`j = 2`)**:
     - `mat[0][2] = 4` (even $\rightarrow +1$)
     - `mat[1][2] = 2` (even $\rightarrow +1$)
     - `mat[2][2] = 4` (even $\rightarrow +1$)
     - `mat[3][2] = 32` (even $\rightarrow +1$)
     - Total `curr = 4`. Since $4 > 3$, update `maxEven = 4, maxCol = 2`.
3. **Display**:
   - Prints `[2, 4]`.

### 3. Step-by-Step Dry Run

Matrix ($4 \times 3$):
```
       Col 0      Col 1      Col 2
Row 0:  34 (E)     1 (O)      4 (E)
Row 1:   3 (O)     4 (E)      2 (E)
Row 2:   3 (O)    66 (E)      4 (E)
Row 3:  23 (O)    44 (E)     32 (E)
```

| Column `j` | Even Numbers Present | Count `curr` | Comparison (`curr > maxEven`) | `maxCol` | `maxEven` |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **0** | `34` | 1 | Baseline | 0 | 1 |
| **1** | `4, 66, 44` | 3 | $3 > 1$ (**True**) | **1** | **3** |
| **2** | `4, 2, 4, 32` | 4 | $4 > 3$ (**True**) | **2** | **4** |

Output: **`[2, 4]`**

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\text{cols} \times \text{rows})$  
  Each cell is tested for even parity once using constant time modulo operations $O(1)$.
- **Space Complexity:** $O(1)$  
  Uses only constant extra space for counter variables.

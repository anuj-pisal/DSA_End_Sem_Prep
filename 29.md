# Problem Title: Find the Row Index with Maximum Sum in a 2D Matrix

## Problem Statement
Given a 2D matrix `mat` of integers with `rows` rows and `cols` columns, find the **0-indexed row** that has the **maximum sum of elements**, along with the sum itself.

Output the result in the format `[maxRow, maxSum]`.

---

## Sample Examples

### Example 1
- **Input Matrix:**
  ```text
  [
    [34,  1,  4],    // Row 0 sum = 39
    [ 3,  4,  2],    // Row 1 sum = 9
    [ 3, 66,  4],    // Row 2 sum = 73
    [23, 44, 32]     // Row 3 sum = 99
  ]
  ```
- **Output:** `[3, 99]`
- **Explanation:**  
  - Row 0 sum: $34 + 1 + 4 = 39$
  - Row 1 sum: $3 + 4 + 2 = 9$
  - Row 2 sum: $3 + 66 + 4 = 73$
  - Row 3 sum: $23 + 44 + 32 = 99$  
  Row 3 has the highest sum ($99$).

### Example 2
- **Input Matrix:**
  ```text
  [
    [10, 20],
    [5,  5]
  ]
  ```
- **Output:** `[0, 30]`
- **Explanation:**  
  Row 0 sum is 30, Row 1 sum is 10. The maximum is at row 0.

### Example 3
- **Input Matrix:**
  ```text
  [
    [-5, -1],
    [-2, -3]
  ]
  ```
- **Output:** `[1, -5]`
- **Explanation:**  
  Row 0 sum is $-6$, Row 1 sum is $-5$. Since $-5 > -6$, Row 1 has the higher sum.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
To find which row yields the largest sum:
1. **Row 0 Baseline:**  
   Calculate the sum of all elements in the very first row (`Row 0`). Set `maxRow = 0` and `maxSum` equal to this initial sum.
2. **Scan Remaining Rows:**  
   Loop through each subsequent row $i$ from $1$ to $\text{rows} - 1$:
   - Compute `curr`, the sum of row $i$.
   - If `curr > maxSum`, we found a row with a higher total! Update:
     - `maxSum = curr`
     - `maxRow = i`
3. After checking all rows, print `[maxRow, maxSum]`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int mat[][3] = {{34,1,4}, {3,4,2}, {3,66,4}, {23,44,32}};
    int cols = 3, rows = 4; 
    int maxRow = 0;
    int maxSum = 0;

    for(int j=0; j<cols; j++) {
        maxSum += mat[0][j];
    }    

    for(int i=1; i<rows; i++) {
        int curr = 0;
        for(int j=0; j<cols; j++) {
            curr += mat[i][j];
        }
        if(curr > maxSum) {
            maxSum = curr;
            maxRow = i;
        }
    }

    cout << "[" << maxRow << ", " << maxSum << "]";
    
    return 0;
}
```

1. **Matrix Definition**:
   - 4 rows and 3 columns.
2. **First Loop (`for(int j=0; j<cols; j++)`)**:
   - Adds elements of row 0: `mat[0][0] + mat[0][1] + mat[0][2] = 34 + 1 + 4 = 39`.
   - `maxSum = 39`, `maxRow = 0`.
3. **Nested Loops for Subsequent Rows**:
   - Outer loop `i` ranges from `1` to `3`.
   - Inner loop `j` sums all columns for row `i`:
     - Row 1: `curr = 3 + 4 + 2 = 9`. Is $9 > 39$? No.
     - Row 2: `curr = 3 + 66 + 4 = 73`. Is $73 > 39$? **Yes!** Update `maxSum = 73, maxRow = 2`.
     - Row 3: `curr = 23 + 44 + 32 = 99`. Is $99 > 73$? **Yes!** Update `maxSum = 99, maxRow = 3`.
4. **Display**:
   - Prints `[3, 99]`.

---

### 3. Step-by-Step Dry Run

| Row `i` | Elements in Row | Row Sum (`curr`) | Comparison (`curr > maxSum`) | `maxRow` | `maxSum` |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **0** | `34, 1, 4` | 39 | Initial Baseline | 0 | 39 |
| **1** | `3, 4, 2` | 9 | $9 > 39$ (False) | 0 | 39 |
| **2** | `3, 66, 4` | 73 | $73 > 39$ (**True**) | **2** | **73** |
| **3** | `23, 44, 32` | 99 | $99 > 73$ (**True**) | **3** | **99** |

Result: `[3, 99]`

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\text{rows} \times \text{cols})$  
  Each cell in the 2D matrix is accessed exactly once. For a $4 \times 3$ matrix, this is $12$ operations.
- **Space Complexity:** $O(1)$  
  Only uses a few scalar variables (`maxRow`, `maxSum`, `curr`), requiring constant extra space.

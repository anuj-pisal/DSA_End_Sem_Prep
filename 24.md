# Problem Title: Plus One (LeetCode 66)

## Problem Statement
You are given a large integer represented as an integer array `digits`, where each `digits[i]` is the $i$-th digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading `0`'s.

Increment the large integer by **one** (`+1`) and return the resulting array of digits.

---

## Sample Examples

### Example 1
- **Input Digits:** `[9, 9, 9]`
- **Output:** `1000`
- **Explanation:**  
  The array represents the number $999$.  
  $999 + 1 = 1000$.  
  The resulting array is `[1, 0, 0, 0]`.

### Example 2
- **Input Digits:** `[1, 2, 3]`
- **Output:** `124`
- **Explanation:**  
  The array represents the integer $123$.  
  $123 + 1 = 124$.  
  The resulting array is `[1, 2, 4]`.

### Example 3
- **Input Digits:** `[1, 2, 9]`
- **Output:** `130`
- **Explanation:**  
  $129 + 1 = 130$. Adding $1$ to $9$ produces $0$ with a carry of $1$ into the tens place ($2 + 1 = 3$).

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
Just like grade school addition:
- We add $1$ starting from the **rightmost digit** (least significant digit).
- If the rightmost digit is strictly less than 9 (e.g., 3), we simply increment it to 4 and we are done!
- If the digit is 9:
  - $9 + 1 = 10$, so that digit becomes $0$, and a **carry** of $1$ ripples leftward into the next digit.
- We continue propagating the carry leftwards:
  - If at any point the carry becomes 0, we can break out of the loop early!
- **Special Case (All 9s):**  
  If every digit in the array was 9 (e.g., `[9, 9, 9]`), all digits become `0`, and a carry of `1` survives past the leftmost digit. In this case, we insert `1` at the very front (`digits.insert(digits.begin(), 1)`), resulting in `[1, 0, 0, 0]`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
#include<vector>
using namespace std;

vector<int> plusOne(vector<int>& digits) {
    int carry = 1;
    for(int i=digits.size()-1; i>=0; i--) {
        int sum = digits.at(i) + carry;
        digits[i] = sum % 10;
        carry = sum / 10;
        if(carry == 0) break;
    }

    if(carry == 1) {
        digits.insert(digits.begin() + 0, 1);
    }

    return digits;
}

int main()
{
    vector<int> d;
    d.push_back(9);
    d.push_back(9);
    d.push_back(9);
    d = plusOne(d);

    for(int val : d) 
        cout << val;

    return 0;
}
```

1. **`carry` Initialization**:
   - `int carry = 1;` initializes the value we want to add to the number.
2. **Backward Loop (`for (int i = digits.size() - 1; i >= 0; i--)`)**:
   - `int sum = digits.at(i) + carry;`: Adds current digit and incoming carry.
   - `digits[i] = sum % 10;`: Stores the unit digit ($0$ to $9$).
   - `carry = sum / 10;`: Calculates carry forward ($0$ or $1$).
   - `if (carry == 0) break;`: Optimization that stops immediately when no carry remains.
3. **Handling Overflow Beyond Most Significant Digit**:
   - `if (carry == 1) digits.insert(digits.begin() + 0, 1);`:  
     If carry is still 1 after exhausting all digits, inserts a new digit `1` at index 0.
4. **`main()` Function**:
   - Builds vector `[9, 9, 9]`, calls `plusOne(d)`, and prints `1000`.

---

### 3. Step-by-Step Dry Run (Tracing `[9, 9, 9]`)

- Initial: `digits = [9, 9, 9]`, `carry = 1`.

| Iteration (`i`) | `digits[i]` | `sum = digits[i] + carry` | `digits[i] = sum % 10` | `carry = sum / 10` | Action |
| :---: | :---: | :---: | :---: | :---: | :--- |
| `i = 2` | 9 | $9 + 1 = 10$ | $0$ | $1$ | Continue |
| `i = 1` | 9 | $9 + 1 = 10$ | $0$ | $1$ | Continue |
| `i = 0` | 9 | $9 + 1 = 10$ | $0$ | $1$ | Loop ends |

- After loop: `digits = [0, 0, 0]`, `carry == 1`.
- `digits.insert(digits.begin(), 1)` $\rightarrow$ `digits = [1, 0, 0, 0]`.

Final Result: **`1000`**.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  - In the worst case (all 9s), it traverses $n$ digits and shifts elements when inserting at the front.
  - In the best case (last digit is $< 9$, e.g. `123 \rightarrow 124`), it runs in $O(1)$ time by breaking on the very first step!
- **Space Complexity:** $O(1)$ auxiliary space  
  Modifications are performed in-place within the given vector (at most allocating 1 additional slot if the number of digits grows).

---

### 5. Edge Cases
- **Single digit 9 (`[9]`):** Becomes `[1, 0]`.
- **Single digit non-9 (`[0]` to `[8]`):** Increments directly to `[1]` to `[9]`.
- **Leading Zeroes:** Problem definition guarantees no leading zeroes exist in the input.

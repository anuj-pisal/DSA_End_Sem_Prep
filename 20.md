# Problem Title: Move Zeroes to End of Array (LeetCode 283)

## Problem Statement
Given an integer array `arr`, move all `0`'s to the **end of the array** while maintaining the **relative order** of all non-zero elements.

> [!IMPORTANT]  
> You must perform this **in-place** without creating a copy of the array and minimize the total number of operations.

---

## Sample Examples

### Example 1
- **Input Array:** `arr = [1, 2, 3, 0, 2, 4, 0, 1, 5, 0, 0]`
- **Output:**
  ```text
  1 2 3 2 4 1 5 0 0 0 0 
  ```
- **Explanation:**  
  All non-zero elements (`1, 2, 3, 2, 4, 1, 5`) stay in their exact initial relative order at the front of the array, while all four `0`'s are shifted to the end.

### Example 2
- **Input Array:** `arr = [0, 1, 0, 3, 12]`
- **Output:**
  ```text
  1 3 12 0 0 
  ```
- **Explanation:**  
  The non-zero numbers `1, 3, 12` maintain their sequence, and both zeroes are pushed to indices 3 and 4.

### Example 3
- **Input Array:** `arr = [0]`
- **Output:**
  ```text
  0 
  ```
- **Explanation:** An array with only a single zero remains `[0]`.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach (Two-Pointer Snowball Technique)
We need to collect all non-zero numbers towards the front and let the zeroes collect behind them.

We use two pointers:
- **`i` (Slow Pointer):** Marks the boundary where the next non-zero number belongs.
- **`j` (Fast Pointer):** Explores and scans every element of the array from left to right.

#### The Core Logic:
- As `j` scans through the array:
  - If `arr[j] == 0`: Do nothing, just let `j` keep moving forward.
  - If `arr[j] != 0`: We have found a non-zero element! We swap it with `arr[i]` (`swap(arr[i], arr[j])`), and advance `i++`.
- Why does this work?
  - If no zeroes have been encountered yet, `i` and `j` are at the same index, so `swap(arr[i], arr[j])` simply swaps an element with itself.
  - Once zeroes are encountered, `i` stays behind resting on the first `0`, while `j` moves ahead. The moment `j` hits a non-zero element, swapping puts the non-zero at `i` and pushes the `0` forward to `j`!

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int arr[] = {1,2,3,0,2,4,0,1,5,0,0};
    int i=0, j=0;
    int n = sizeof(arr) / sizeof(arr[0]);

    while(j < n) {
        if(arr[j] != 0) {
            swap(arr[i], arr[j]);
            i++;
        }
        j++;
    }
    
    for(int x : arr) {
        cout << x << " ";
    }

    return 0;
}
```

1. **Pointer Setup**:
   - `int i = 0, j = 0;`: Both pointers start at index 0.
2. **Scan & Swap Loop (`while (j < n)`)**:
   - `if (arr[j] != 0)`:
     - `swap(arr[i], arr[j]);`: Moves the non-zero element to the leftmost available slot `i`.
     - `i++;`: Increments the write pointer so the next non-zero will go to the following slot.
   - `j++;`: Advances the scan pointer on every single step.
3. **Display**:
   - A range-based `for (int x : arr)` loop prints out the reordered array.

### 3. Step-by-Step Execution Walkthrough

Trace on `arr = [0, 1, 0, 3, 12]`:

| Step (`j`) | `arr[j]` | Is `arr[j] != 0`? | Action | `i` after step | Array State |
| :---: | :---: | :---: | :--- | :---: | :--- |
| **Start** | - | - | - | 0 | `[0, 1, 0, 3, 12]` |
| `j = 0` | 0 | False | Do nothing | 0 | `[0, 1, 0, 3, 12]` |
| `j = 1` | 1 | **True** | `swap(arr[0], arr[1])` | 1 | `[1, 0, 0, 3, 12]` |
| `j = 2` | 0 | False | Do nothing | 1 | `[1, 0, 0, 3, 12]` |
| `j = 3` | 3 | **True** | `swap(arr[1], arr[3])` | 2 | `[1, 3, 0, 0, 12]` |
| `j = 4` | 12 | **True** | `swap(arr[2], arr[4])` | 3 | `[1, 3, 12, 0, 0]` |

Result: `[1, 3, 12, 0, 0]` (All zeroes naturally pushed to the back).

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  The fast pointer `j` visits every index from `0` to `n - 1` exactly once. Each check and swap operation takes constant $O(1)$ time.
- **Space Complexity:** $O(1)$  
  Operates completely in-place; no new arrays or data structures are created.

---

### 5. Edge Cases
- **No Zeroes in Array:** e.g., `[1, 2, 3]`. `i` and `j` move together; array remains unchanged.
- **All Zeroes in Array:** e.g., `[0, 0, 0]`. `arr[j] != 0` is never satisfied; array remains `[0, 0, 0]`.
- **Zeroes Already at the End:** e.g., `[1, 2, 0, 0]`. Operates correctly without altering non-zero ordering.

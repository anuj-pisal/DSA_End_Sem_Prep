# Problem Title: Count Maximum Consecutive One's in an Array (LeetCode 485)

## Problem Statement
Given a binary array `arr` (an array consisting only of `0`s and `1`s), return the **maximum number of consecutive 1's** in the array.

---

## Sample Examples

### Example 1
- **Input Array:** `arr = [1, 1, 0, 0, 1, 1, 1, 1, 0, 0]`
- **Output:** `Max : 4`
- **Explanation:**  
  - The first cluster of consecutive 1s has length 2 (`arr[0]` to `arr[1]`).
  - The second cluster of consecutive 1s has length 4 (`arr[4]` to `arr[7]`).
  - The maximum consecutive 1s found is **4**.

### Example 2
- **Input Array:** `arr = [1, 0, 1, 1, 0, 1]`
- **Output:** `Max : 2`
- **Explanation:**  
  The longest sequence of uninterrupted 1s has length 2.

### Example 3
- **Input Array:** `arr = [0, 0, 0]`
- **Output:** `Max : 0`
- **Explanation:**  
  There are no 1s in the array, so the maximum consecutive count is 0.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
To find the longest unbroken streak of `1`s:
- Think of a tally counter that counts consecutive steps:
  - Every time you see a `1`, your current streak increases by 1 (`curr++`).
  - The moment you step on a `0`, the streak is broken, so you must reset your streak counter back to zero (`curr = 0`).
- Throughout this process, you also maintain a record of the highest streak ever achieved (`m = max(m, curr)`).

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int arr[] = {1,1,0,0,1,1,1,1,0,0};
    int curr = 0, m = 0;
    int n = sizeof(arr) / sizeof(arr[0]);

    for(int i=0; i<n; i++) {
        if(arr[i] == 1) {
            curr++;
        }
        else {
            curr = 0;
        }
        m = max(m, curr);
    }    

    cout << "Max : " << m;
    return 0;
}
```

1. **Variables**:
   - `int curr = 0;`: Keeps track of the current streak of consecutive 1s.
   - `int m = 0;`: Stores the global maximum streak found so far.
2. **Iteration Loop (`for (int i = 0; i < n; i++)`)**:
   - `if (arr[i] == 1)`: Increments `curr++`.
   - `else`: When `arr[i] == 0`, streak is interrupted; resets `curr = 0`.
   - `m = max(m, curr);`: Updates the all-time maximum after evaluating each element.
3. **Output**:
   - Displays `Max : m`.

---

### 3. Step-by-Step Dry Run

Array: `[1, 1, 0, 0, 1, 1, 1, 1, 0, 0]`

| Index `i` | Value `arr[i]` | Condition | Current Streak (`curr`) | Maximum (`m`) |
| :---: | :---: | :---: | :---: | :---: |
| `0` | 1 | `arr[i] == 1` | 1 | 1 |
| `1` | 1 | `arr[i] == 1` | 2 | 2 |
| `2` | 0 | `arr[i] == 0` | 0 (reset) | 2 |
| `3` | 0 | `arr[i] == 0` | 0 | 2 |
| `4` | 1 | `arr[i] == 1` | 1 | 2 |
| `5` | 1 | `arr[i] == 1` | 2 | 2 |
| `6` | 1 | `arr[i] == 1` | 3 | 3 |
| `7` | 1 | `arr[i] == 1` | 4 | **4** |
| `8` | 0 | `arr[i] == 0` | 0 (reset) | 4 |
| `9` | 0 | `arr[i] == 0` | 0 | 4 |

Final Result: **`4`**.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  The array is traversed exactly once from index `0` to `n - 1`.
- **Space Complexity:** $O(1)$  
  Only two scalar integer variables (`curr`, `m`) are maintained.

---

### 5. Edge Cases
- **All 1s:** e.g., `[1, 1, 1]`. `curr` never resets, correctly returning `3`.
- **All 0s:** e.g., `[0, 0]`. `curr` stays 0, correctly returning `0`.
- **1s at the very end:** e.g., `[0, 1, 1]`. Because `m = max(m, curr)` is called inside the loop, streaks at the very end are captured even without a terminating zero.

# Problem Title: Check if Given Array is Sorted

## Problem Statement
Given an array of integers, determine whether the array is **sorted** in non-decreasing (ascending) order.

- Return `true` (or `"YES"`) if every element is less than or equal to its succeeding element:
  $$arr[i] \le arr[i + 1] \quad \text{for all } 0 \le i < \text{len} - 1$$
- Return `false` (or `"NO"`) if any element is strictly greater than the element next to it.

---

## Sample Examples

### Example 1
- **Input Array:** `a = [3, 23, 56, 88, 98]`
- **Output:** `a is sorted ? --> YES`
- **Explanation:**  
  Let's check each adjacent pair:
  - $3 \le 23$ (True)
  - $23 \le 56$ (True)
  - $56 \le 88$ (True)
  - $88 \le 98$ (True)  
  All pairs satisfy the condition, so the array is sorted.

### Example 2
- **Input Array:** `b = [32, 5, 11, 23, 7]`
- **Output:** `b is sorted ? --> NO`
- **Explanation:**  
  Checking the first pair:
  - $32 > 5$ $\rightarrow$ The order is violated immediately!  
  The function returns `false` / `"NO"`.

### Example 3
- **Input Array:** `c = [10]`
- **Output:** `c is sorted ? --> YES`
- **Explanation:** An array with a single element has no pairs to violate the sorted order, so it is trivially sorted.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
To verify whether an entire array is sorted in ascending order:
- You don't need to check every pair against every other pair.
- You only need to compare **adjacent neighbors**: `arr[i]` and `arr[i + 1]`.
- If an array is sorted, each element must be $\le$ the next one.
- If we find even a **single pair** where the left element is strictly greater than the right element (`arr[i] > arr[i + 1]`), we can stop immediately and conclude that the array is **not sorted**.
- If we finish scanning the entire array from beginning to end without encountering any violation, then the array is guaranteed to be **sorted**.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

bool isSorted(int arr[], int len) {
    for(int i=0; i<len-1; i++) {
        if(arr[i] > arr[i+1])
            return false;
    }
    return true;
}

int main()
{
    int a[] = {3,23,56,88,98};
    int size_a = sizeof(a) / sizeof(a[0]);

    int b[] = {32,5,11,23,7};
    int size_b = sizeof(b) / sizeof(b[0]);

    cout << "a is sorted ? --> " << (isSorted(a, size_a) ? "YES" : "NO") << endl;
    cout << "b is sorted ? --> " << (isSorted(b, size_b) ? "YES" : "NO");

    return 0;
}
```

1. **`isSorted(int arr[], int len)` Function**:
   - `for(int i = 0; i < len - 1; i++)`:
     - Note the boundary `len - 1`: Because we compare `arr[i]` with `arr[i + 1]`, stopping at `len - 2` prevents accessing memory out-of-bounds at index `len`.
   - `if (arr[i] > arr[i + 1]) return false;`:
     - As soon as a decrease is observed, it exits early and returns `false`.
   - `return true;`:
     - If the loop finishes without returning `false`, the array must be sorted.
2. **`main()` Function**:
   - Tests two arrays: `a` (sorted) and `b` (unsorted).
   - Computes lengths dynamically using `sizeof(arr) / sizeof(arr[0])`.
   - Uses ternary operator `isSorted(...) ? "YES" : "NO"` to print the answer.

---

### 3. Step-by-Step Dry Run

#### Case A: Array `a = [3, 23, 56, 88, 98]` (`len = 5`)
- Loop runs for $i = 0, 1, 2, 3$:
  - $i = 0$: $a[0] (3) > a[1] (23)$? False.
  - $i = 1$: $a[1] (23) > a[2] (56)$? False.
  - $i = 2$: $a[2] (56) > a[3] (88)$? False.
  - $i = 3$: $a[3] (88) > a[4] (98)$? False.
- Loop ends naturally $\rightarrow$ returns `true` (`YES`).

#### Case B: Array `b = [32, 5, 11, 23, 7]` (`len = 5`)
- $i = 0$: $b[0] (32) > b[1] (5)$? **True!**
- Immediately returns `false` (`NO`) on the very first comparison.

---

### 4. Complexity Analysis

- **Time Complexity:**
  - **Best Case: $O(1)$**  
    If the first two elements are out of order (like array `b`), the function terminates after just 1 comparison.
  - **Worst Case: $O(n)$**  
    If the array is already sorted (like array `a`) or the violation is at the very last pair, the algorithm makes $n - 1$ comparisons.
  - **Average Case: $O(n)$**
- **Space Complexity: $O(1)$**  
  Uses no additional memory; only 1 index loop counter.

---

### 5. Edge Cases
- **Empty Array (`len = 0`) or Single Element (`len = 1`):**  
  The loop condition `i < len - 1` is not satisfied ($0 < 0$ or $0 < -1$ if unsigned), so it immediately returns `true`. An array with 0 or 1 element is always considered sorted.
- **Duplicates (`arr[i] == arr[i+1]`):**  
  Since the condition checks strictly greater (`>`), duplicate adjacent elements (e.g., `[2, 2, 3, 3]`) are correctly recognized as sorted.

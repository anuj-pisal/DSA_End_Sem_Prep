# Problem Title: Shifting Array Elements by 1 Position (Cyclic Rotation)

## Problem Statement
Given an array of integers, shift its elements cyclically by 1 position.

- **Right Cyclic Shift (as performed by the code):** Each element moves one index to the right (`arr[i+1] = arr[i]`), and the last element wraps around to index `0`.
- **Left Cyclic Shift:** Each element moves one index to the left (`arr[i] = arr[i+1]`), and the first element wraps around to index `n-1`.

---

## Sample Examples

### Example 1 (Cyclic Shift in `17.cpp`)
- **Input Array:** `arr = [1, 2, 3, 4]`
- **Output:**
  ```text
  After shifting left by 1 :
  4 1 2 3 
  ```
- **Explanation:**  
  The last element `4` is saved in `temp`. Elements `1, 2, 3` are shifted one position to the right into indices `1, 2, 3`. Finally, `temp` (`4`) is placed at index `0`.

### Example 2
- **Input Array:** `arr = [10, 20, 30, 40, 50]`
- **Output:**
  ```text
  50 10 20 30 40 
  ```
- **Explanation:**  
  The last value `50` moves to the front, and all other numbers slide right by 1 index.

### Example 3 (True Left Shift Comparison)
- **Input Array:** `arr = [1, 2, 3, 4]`
- **True Left Shift Output:** `2 3 4 1`
- **Explanation:**  
  In a left shift, `arr[0]` (`1`) is preserved, all numbers slide left by 1 position, and `1` wraps around to the last index.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
When shifting an array cyclically by 1 position:
- If we overwrite an element before saving its value, we lose that data forever.
- Therefore, we must:
  1. Store the boundary element that will be overwritten in a temporary variable (`temp`).
  2. Shift the remaining elements in order (starting from the direction that prevents overwriting unsaved data).
  3. Place `temp` into the vacant boundary slot.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int arr[] = {1,2,3,4};
    int n = sizeof(arr) / sizeof(arr[0]);
    int temp = arr[n-1];

    for(int i=n-2; i>=0; i--) {
        arr[i+1] = arr[i];
    }
    arr[0] = temp;

    cout << "After shifting left by 1 :" << endl;
    for(int x : arr) {
        cout << x << " ";
    }

    return 0;
}
```

1. **Saving the Last Element**:
   - `int temp = arr[n-1];` stores `arr[3] = 4`.
2. **Backward Shift Loop**:
   - `for(int i = n - 2; i >= 0; i--)`:  
     We must iterate **backwards** from index `n - 2` down to `0`.  
     If we moved forward (`0` to `n - 2`), `arr[1]` would overwrite `arr[2]`, which would overwrite `arr[3]`, duplicating `arr[0]` across the entire array!
   - `arr[i + 1] = arr[i];`: Moves each element one position to the right.
3. **Placing `temp`**:
   - `arr[0] = temp;` places the preserved last element into index `0`.
4. **Display**:
   - Prints the elements separated by space.

---

### 3. Step-by-Step Walkthrough (Tracing `arr = [1, 2, 3, 4]`)

- Initially: `temp = arr[3] = 4`
- `i = 2`: `arr[3] = arr[2]` $\rightarrow$ Array is `[1, 2, 3, 3]`
- `i = 1`: `arr[2] = arr[1]` $\rightarrow$ Array is `[1, 2, 2, 3]`
- `i = 0`: `arr[1] = arr[0]` $\rightarrow$ Array is `[1, 1, 2, 3]`
- After loop: `arr[0] = temp` $\rightarrow$ Array is `[4, 1, 2, 3]`

---

### 4. Important Concept Note: Right Shift vs Left Shift

> [!NOTE]  
> The printed text in the file says `"After shifting left by 1"`, but the algorithm implemented above actually performs a **Cyclic Right Shift** (`[1, 2, 3, 4] \rightarrow [4, 1, 2, 3]`).
>
> If your practical question specifically asks for a **Cyclic Left Shift** (`[1, 2, 3, 4] \rightarrow [2, 3, 4, 1]`), the logic is:
> ```cpp
> int temp = arr[0]; // Save the first element
> for (int i = 0; i < n - 1; i++) {
>     arr[i] = arr[i + 1]; // Shift forward (leftwards)
> }
> arr[n - 1] = temp; // Place saved element at the end
> ```

---

### 5. Complexity Analysis

- **Time Complexity:** $O(n)$  
  The loop runs $n - 1$ times, performing constant work per iteration.
- **Space Complexity:** $O(1)$  
  Only a single temporary variable `temp` is used; no extra array is needed.

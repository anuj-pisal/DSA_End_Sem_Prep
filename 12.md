# Problem Title: Find the Largest and Smallest Element from a Given Array

## Problem Statement
Given an unsorted 1D array of integers, find and return:
1. The **largest (maximum)** element in the array.
2. The **smallest (minimum)** element in the array.

---

## Sample Examples

### Example 1
- **Input Array:** `[32, 11, 5, 76, 23, 31, 89]`
- **Output:**
  ```text
  Max : 89
  Min : 5
  ```
- **Explanation:**  
  Looking at all numbers:
  - The highest value present is `89`.
  - The lowest value present is `5`.

### Example 2
- **Input Array:** `[-10, 45, 0, 99, -3, 102]`
- **Output:**
  ```text
  Max : 102
  Min : -10
  ```
- **Explanation:**  
  - Scanning negative and positive numbers: the highest is `102` and the lowest is `-10`.

### Example 3
- **Input Array:** `[42]`
- **Output:**
  ```text
  Max : 42
  Min : 42
  ```
- **Explanation:** When an array has only one element, that single element is both the maximum and minimum.

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
To find the maximum and minimum elements in an unsorted list:
1. **Initialize:** Assume the very first element `arr[0]` is both the smallest (`min`) and largest (`max`).
2. **Iterate:** Walk through every element in the array from beginning to end:
   - For finding the **maximum**: If any element is strictly greater than `max`, update `max = arr[i]`.
   - For finding the **minimum**: If any element is strictly less than `min`, update `min = arr[i]`.
3. Once all elements have been inspected, the final values of `max` and `min` represent the largest and smallest numbers.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int smallest(int arr[], int n) {
    int min = arr[0];
    for(int i=0; i<n; i++) {
        if(arr[i] < min) 
            min = arr[i];
    }
    return min;
}

int largest(int arr[], int n) {
    int max = arr[0];
    for(int i=0; i<n; i++) {
        if(arr[i] > max) 
            max = arr[i];
    }
    return max;
}

int main()
{
    int arr[] = {32,11,5,76,23,31,89};
    int n = sizeof(arr) / sizeof(arr[0]);
    cout << "Max : " << largest(arr, n) << endl;
    cout << "Min : " << smallest(arr, n);
    return 0;
}
```

1. **`smallest(int arr[], int n)` Function**:
   - `int min = arr[0];` sets the baseline candidate to the first element.
   - `for(int i = 0; i < n; i++)`:
     - Checks if `arr[i] < min`.
     - If true, updates `min = arr[i]`.
   - Returns the smallest value found.
2. **`largest(int arr[], int n)` Function**:
   - `int max = arr[0];` sets the baseline candidate to the first element.
   - `for(int i = 0; i < n; i++)`:
     - Checks if `arr[i] > max`.
     - If true, updates `max = arr[i]`.
   - Returns the largest value found.
3. **`main()` Function**:
   - Defines test array `arr = {32, 11, 5, 76, 23, 31, 89}`.
   - Determines array size `n` using `sizeof(arr) / sizeof(arr[0])`.
   - Calls `largest(arr, n)` and `smallest(arr, n)` and prints the results.

---

### 3. Step-by-Step Execution Trace

Array: `[32, 11, 5, 76, 23, 31, 89]`

#### Tracing `largest()`:
- Start: `max = 32`
- Check `arr[1] = 11`: $11 > 32$ (False) $\rightarrow$ `max = 32`
- Check `arr[2] = 5`: $5 > 32$ (False) $\rightarrow$ `max = 32`
- Check `arr[3] = 76`: $76 > 32$ (**True**) $\rightarrow$ `max = 76`
- Check `arr[4] = 23`: $23 > 76$ (False) $\rightarrow$ `max = 76`
- Check `arr[5] = 31`: $31 > 76$ (False) $\rightarrow$ `max = 76`
- Check `arr[6] = 89`: $89 > 76$ (**True**) $\rightarrow$ `max = 89`
- Return: `89`.

#### Tracing `smallest()`:
- Start: `min = 32`
- Check `arr[1] = 11`: $11 < 32$ (**True**) $\rightarrow$ `min = 11`
- Check `arr[2] = 5`: $5 < 11$ (**True**) $\rightarrow$ `min = 5`
- Check `arr[3] = 76`: $76 < 5$ (False) $\rightarrow$ `min = 5`
- Check `arr[4] = 23`: $23 < 5$ (False) $\rightarrow$ `min = 5`
- Check `arr[5] = 31`: $31 < 5$ (False) $\rightarrow$ `min = 5`
- Check `arr[6] = 89`: $89 < 5$ (False) $\rightarrow$ `min = 5`
- Return: `5`.

---

### 4. Complexity Analysis

- **Time Complexity:** $O(n)$  
  - Each function makes a single linear pass over the array of size $n$.
  - Total comparisons: $n$ comparisons for min + $n$ comparisons for max = $2n = O(n)$.
- **Space Complexity:** $O(1)$  
  Only uses two scalar integer variables (`min`, `max`), requiring constant extra space.

---

### 5. Optimization Note
Both the minimum and maximum can also be computed in a single function in a single loop pass (or pairwise comparisons using $\approx 1.5n$ comparisons), but separating them into individual functions keeps the code modular and clean.

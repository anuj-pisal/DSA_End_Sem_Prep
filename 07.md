# Problem Title: Initialize and Display Array Elements (Array Memory Representation)

## Problem Statement
Write a program to dynamically take the size and elements of a 1D integer array from the user, store them, and display each element in a structured tabular format showing:
1. The **Array Index** (`0` to `len - 1`)
2. The **Memory Address** of each element (`(arr + i)`)
3. The **Stored Value** (`arr[i]`)

This exercise demonstrates how arrays are allocated contiguously in computer memory.

---

## Sample Examples

### Example 1
- **User Input:**
  ```
  Enter len : 4
  Enter elements : 
  Enter arr[0] : 10
  Enter arr[1] : 20
  Enter arr[2] : 30
  Enter arr[3] : 40
  ```
- **Output:**
  ```text
  Index :   0               1               2               3
  Address : 0x7ffd98b0a1a0  0x7ffd98b0a1a4  0x7ffd98b0a1a8  0x7ffd98b0a1ac
  arr[i] :  10              20              30              40
  ```
- **Explanation:**  
  Notice the memory addresses in hexadecimal: `...a0`, `...a4`, `...a8`, `...ac`.  
  Each address increases by exactly **4 bytes**, which is the exact size of an `int` in C++ (`sizeof(int) = 4`).

### Example 2
- **User Input:**
  ```
  Enter len : 3
  Enter elements : 
  Enter arr[0] : 5
  Enter arr[1] : -2
  Enter arr[2] : 99
  ```
- **Output:**
  ```text
  Index :   0               1               2
  Address : 0x61fe08        0x61fe0c        0x61fe10
  arr[i] :  5               -2              99
  ```
- **Explanation:** The array elements are stored at 3 consecutive 4-byte memory locations.

## Detailed Solution (In Simple English)

### 1. Intuition & Key Concepts

1. **What is an Array?**  
   An array is a collection of elements of the same data type stored at **contiguous (adjacent) memory locations**.

2. **Pointer Arithmetic (`arr + i`):**
   - In C++, the name of the array `arr` acts as a constant pointer pointing to the first element (`&arr[0]`).
   - When we write `arr + i`, the compiler advances the address by $i \times \text{sizeof(int)}$ bytes.
   - For example, if `arr` starts at memory location `1000`, then:
     - `arr + 0` = `1000`
     - `arr + 1` = `1004`
     - `arr + 2` = `1008`
     - `arr + 3` = `1012`

3. **Subscript Notation vs Pointer Dereferencing:**
   - `arr[i]` is identical to `*(arr + i)`.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

void display(int arr[], int len) {
    cout << "Index : \t";
    for(int i=0; i<len; i++) {
        cout << i << "\t\t";
    }
    cout << "\nAddress : \t";
    for(int i=0; i<len; i++) {
        cout << (arr + i) << "\t";
    }
    cout << "\narr[i] : \t";
    for(int i=0; i<len; i++) {
        cout << arr[i] << "\t\t";
    }
}
 
int main()
{
    int len;
    cout << "Enter len : ";
    cin >> len;
    
    int arr[len];
    cout << "Enter elements : \n";

    for(int i=0; i<len; i++) {
        cout << "Enter arr[" << i << "] : ";
        cin >> arr[i];
    }

    display(arr, len);
}
```

1. **Input Phase in `main()`**:
   - `cin >> len;` gets the number of elements from the user.
   - `int arr[len];` allocates space for `len` integers on the stack.
   - The `for` loop prompts the user to enter a value for each index from `0` to `len - 1`.
2. **Display Function `display(int arr[], int len)`**:
   - First `for` loop prints row 1: The index values (`0, 1, 2, ...`).
   - Second `for` loop prints row 2: The memory address of each element using `(arr + i)`.
   - Third `for` loop prints row 3: The actual integer values stored at `arr[i]`.
   - Tabs (`\t`) are used to align the columns neatly.

### 3. Memory Layout Visualization

For an array of size 3 with values `[10, 20, 30]`:

```
+---------------+-------------------+-------------------+-------------------+
| Row           | Element 0         | Element 1         | Element 2         |
+---------------+-------------------+-------------------+-------------------+
| Index         | 0                 | 1                 | 2                 |
| Address       | 0x1000            | 0x1004            | 0x1008            |
| Byte Offset   | +0 bytes          | +4 bytes          | +8 bytes          |
| Value (arr[i])| 10                | 20                | 30                |
+---------------+-------------------+-------------------+-------------------+
```

---

### 4. Complexity Analysis

- **Time Complexity:** $O(\text{len})$  
  - Reading the array requires 1 loop: $O(\text{len})$.  
  - Displaying the array requires 3 separate linear loops: $3 \times O(\text{len}) = O(\text{len})$.  
  - Overall time is linear in the number of elements.
- **Space Complexity:** $O(\text{len})$  
  - Space is used to store `len` integers in the array `arr`.

---

### 5. Edge Cases & Notes
- **`len <= 0`:** In production code, validate that `len > 0` before declaring the array to avoid undefined behavior.
- **Hexadecimal Addresses:** Memory addresses are printed in hexadecimal format (base 16). The difference between adjacent addresses is always equal to `sizeof(int)` (usually 4 bytes on 32-bit and 64-bit systems).

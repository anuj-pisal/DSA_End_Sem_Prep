# Problem Title: Search an Element using Linear Search

## Problem Statement
Given an array of integers and a `target` element, search for the `target` in the array using the **Linear Search** technique.

- If the element is present in the array, report that the target is found.
- If the element is not found after examining the entire array, report that the target is not present.

---

## Sample Examples

### Example 1
- **Array:** `[23, 22, 11, 54, 3, 24, 78, 99, 64, 84]`
- **Input Target:** `54`
- **Output:** `Target is present in the Array !`
- **Explanation:**  
  Starting from index 0, we check:
  - Index 0: `23 == 54` $\rightarrow$ False
  - Index 1: `22 == 54` $\rightarrow$ False
  - Index 2: `11 == 54` $\rightarrow$ False
  - Index 3: `54 == 54` $\rightarrow$ **True (Match found!)**  
  The search succeeds and terminates immediately.

### Example 2
- **Array:** `[23, 22, 11, 54, 3, 24, 78, 99, 64, 84]`
- **Input Target:** `100`
- **Output:** `Target is not there in the Array !!`
- **Explanation:**  
  The algorithm checks all 10 elements from index 0 to index 9. None of them equal 100. It exits the loop and reports that the target is absent.

### Example 3
- **Array:** `[23, 22, 11, 54, 3, 24, 78, 99, 64, 84]`
- **Input Target:** `23`
- **Output:** `Target is present in the Array !`
- **Explanation:** The target is found right at the very first position (index 0).

---

## Detailed Solution (In Simple English)

### 1. Intuition & Approach
**Linear Search** (also called Sequential Search) is the simplest searching algorithm:
- Imagine looking for a book on an unorganized shelf. You start from the first book on the left, check each book one by one in order, and stop as soon as you find the book you are looking for.
- If you reach the very end of the shelf and haven't found it, then the book isn't there.

#### Steps:
1. Start at index `i = 0`.
2. Compare the element `arr[i]` with the `target`.
3. If `arr[i] == target`, print success and stop immediately.
4. If not equal, move to the next index `i = i + 1`.
5. If the loop ends without finding a match, print failure.

---

### 2. How the C++ Code Works Step-by-Step

```cpp
#include<iostream>
using namespace std;

int main()
{
    int arr[] = {23,22,11,54,3,24,78,99,64,84};
    int len = sizeof(arr) / sizeof(arr[0]);
    
    int target;
    cout << "Enter target : " << endl;
    cin >> target;

    for(int i=0; i<len; i++) {
        if(target == arr[i]) {
            cout << "Target is present in the Array !" << endl;
            return 1;
        }
    }    
    
    cout << "Target is not there in the Array !!" << endl;

    return 0;
}
```

1. **Calculating Array Length**:
   - `int len = sizeof(arr) / sizeof(arr[0]);`
   - `sizeof(arr)` gives total bytes used by the entire array ($10 \times 4 = 40$ bytes).
   - `sizeof(arr[0])` gives the size of one integer element ($4$ bytes).
   - Dividing them gives `40 / 4 = 10` elements.
2. **Taking Input**:
   - User enters the `target` value to look for.
3. **The Search Loop**:
   - `for(int i = 0; i < len; i++)` checks every index from 0 to `len - 1`.
   - `if(target == arr[i])`:
     - If true, prints `"Target is present in the Array !"`.
     - `return 1;` exits the `main()` function immediately, avoiding unnecessary further checks.
4. **Target Not Found**:
   - If all elements have been checked and none matched, the loop ends naturally.
   - The line `cout << "Target is not there in the Array !!";` runs and announces that the element is missing.

---

### 3. Step-by-Step Dry Run (Target = 3)

| Step (`i`) | Current Element `arr[i]` | Comparison (`arr[i] == 3`) | Action |
| :---: | :---: | :---: | :--- |
| 0 | 23 | $23 == 3$ (False) | Continue |
| 1 | 22 | $22 == 3$ (False) | Continue |
| 2 | 11 | $11 == 3$ (False) | Continue |
| 3 | 54 | $54 == 3$ (False) | Continue |
| 4 | 3 | $3 == 3$ (**True**) | Print message & exit |

---

### 4. Complexity Analysis

- **Time Complexity:**
  - **Best Case: $O(1)$**  
    The target is at the very first index (`i = 0`). Only 1 comparison is needed.
  - **Worst Case: $O(n)$**  
    The target is at the very last index or is not present in the array at all. We must perform all $n$ comparisons.
  - **Average Case: $O(n)$**  
    On average, about $n / 2$ comparisons are performed.
- **Space Complexity:** $O(1)$  
  No extra memory or data structures are used; only a few variables (`i`, `len`, `target`).

---

### 5. When to Use Linear Search
- When the array is **unsorted** (Binary Search cannot be used on unsorted arrays).
- When the dataset is small.
- Simple to implement and requires no preprocessing.
